共用參數

表單輸入元件（ShuoInputText、ShuoInputNumber、ShuoSelectMenu、ShuoDatepicker、ShuoCheckbox、ShuoCheckboxGroup、ShuoRadioGroup、ShuoTextarea、ShuoFile、ShuoMonths、ShuoPhone）都支援下列參數，各元件頁面不再重複列出：

size
'xs' | 'sm' | 'md' | 'lg' | 'xl'
元件尺寸，同尺寸元件高度一致。未傳入時依序沿用 UFormField 的 size、全站設定，最後為 lg，見尺寸與 UFormField。
disabled
boolean
停用。未設定時沿用 UForm 的停用狀態。
loading
boolean
顯示轉圈圖示並停用操作。
skeleton
boolean
以骨架覆蓋並暫停互動，保留原排版；切回後保留綁定值，不影響表單驗證。
id
string
輸入框識別碼，未設定時沿用 UFormField。ShuoMonths 指向年數框（窄容器時為總月數框）、ShuoPhone 指向區碼框；ShuoFile 只沿用 UFormField。
name
string
欄位名稱，未設定時沿用 UFormField。

除 ShuoDatepicker（改用 state，見日期選擇器）與 ShuoFile 外，也支援 Nuxt UI 的 color（元件顏色）；除 ShuoDatepicker、ShuoFile 外的輸入框類元件另支援 highlight（強調外框），核取方塊與群組沒有外框，不支援 highlight。ShuoFile 的顏色與錯誤外框沿用 UFormField。

搭配 UForm 與 UFormField

建議外包 UFormField，name 對應 schema 欄位，元件會接入 UFormField 的 id、尺寸、停用與錯誤狀態，並在 input、blur、change 時觸發驗證：

<UFormField label="姓名" name="name" required>
  <ShuoInputText v-model="state.name" />
</UFormField>

下面的元件都沒有傳 size 與 disabled：尺寸來自 UFormField，停用來自 UForm。先按「送出」，可以看到未填欄位的錯誤外框與訊息；全部填好再送出，會跳出通知顯示送出的資料。

元

  <ExampleOptions>

    />
  </ExampleOptions>

    :state="state"
    :disabled="formDisabled"

      <UFormField label="金額" name="amount" :size="fieldSize" required>
        <ShuoInputNumber v-model="state.amount" unit />
      </UFormField>
      <UFormField label="類別" name="type" :size="fieldSize" required>
        <ShuoSelectMenu v-model="state.type" :items="types" />
      </UFormField>

        <ShuoDatepicker v-model="state.date" clearable />
      </UFormField>

        @click="clear"

<script setup lang="ts">
import * as v from 'valibot';

type Size = 'xs' | 'sm' | 'md' | 'lg' | 'xl';

const sizes: Size[] = ['xs', 'sm', 'md', 'lg', 'xl'];
// 元件沒有傳 size、disabled，由 UFormField 與 UForm 決定。
const fieldSize = ref<Size>('md');
const formDisabled = ref(false);

const types = ['一般', '急件'];
const schema = v.object({
  name: requiredText('姓名'),
  amount: requiredNumber('金額'),
  type: requiredText('類別'),
  date: requiredText('申請日期')
});
const state = reactive({
  name: '',
  amount: null as number | null,
  type: '',
  date: ''
});
const toast = useToast();

// 驗證通過才會觸發 submit；先按「送出」可看到各欄位的錯誤外框。
const onSubmit = (event: { data: v.InferOutput<typeof schema> }) => {
  toast.add({
    title: '送出成功',
    description: JSON.stringify(event.data),
    color: 'success'
  });
};
const clear = () => {
  Object.assign(state, { name: '', amount: null, type: '', date: '' });
};
</script>

沿用 Nuxt UI

包裝 Nuxt UI 元件的 Shuo 元件，props 型別繼承底層元件，未自行宣告的 Nuxt UI props 也有自動補全與型別檢查；事件參數也有型別；slots 轉給底層元件，並對外提供與底層相同的 ref。

元件繼承的 props可用的 slots對外提供的 ref
ShuoInputTextUInputleading、default、trailinginputRef
ShuoInputNumberUInputleading、default、trailinginputRef
ShuoTextareaUTextarealeading、default、trailingtextareaRef、autoResize
ShuoFileUInputleading、defaultinputRef
ShuoSelectMenuUSelectMenu全部triggerRef、viewportRef
ShuoCheckboxUCheckboxappend（元件自有）—
ShuoRadioGroupURadioGrouplegend、item-append（元件自有）—
ShuoCheckboxGroupUCheckboxGrouplegend、item-append（元件自有）—
  • 繼承的 props 只用於型別推導，執行時經 $attrs 傳給底層元件。
  • 元件自行處理的 props 不列入繼承，不會出現在自動補全，例如 modelValue。輸入框類元件（ShuoInputText、ShuoInputNumber、ShuoTextarea、ShuoFile）自行顯示載入圖示，固定使用 Nuxt UI 的 appConfig.ui.icons.loading，因此也排除 loadingIcon，寫了不會生效；ShuoSelectMenu 由 USelectMenu 顯示載入圖示，loadingIcon 照常可用。
  • 事件照常經 $attrs 轉給底層元件，型別取自底層元件的 emits，例如 @blur 的參數為 FocusEvent。
  • 核取方塊與群組不支援說明文字（description、descriptionKey）：說明會撐高選項，破壞與輸入框對齊的高度。
  • 核取方塊與群組也不支援 Nuxt UI 的 variant（card、table）、indicator 與 highlight：card、table 的外框與內距會撐高選項；indicator 會移動勾選框，載入中的轉圈圖示固定在左側勾選框的位置；highlight 只改 card、table 的外框顏色。傳入時型別會報錯，執行時也不會套用。

骨架

骨架保留原控制項的排版空間，沿用 size、寬度、textarea 行數及選項群組排列，不另設固定高度。啟用期間不可點擊或鍵盤操作，Tooltip 與已開啟的選單會關閉。

常見用法是編輯頁向後端取資料時，用同一個載入狀態控制所有欄位的骨架。按「重新載入資料」看看：骨架期間版面不變，資料回來後直接填入。

<template>
  <ExampleOptions>
    <ExampleAction
      label="重新載入資料"
      icon="i-lucide-refresh-cw"
      :action="reload"
    />
  </ExampleOptions>

  <div class="grid gap-4 sm:grid-cols-2">
    <UFormField label="申請人">
      <ShuoInputText v-model="form.name" :skeleton="pending" />
    </UFormField>
    <UFormField label="類別">
      <ShuoSelectMenu v-model="form.type" :items="types" :skeleton="pending" />
    </UFormField>
    <UFormField label="說明" class="sm:col-span-2">
      <ShuoTextarea v-model="form.note" :rows="3" :skeleton="pending" />
    </UFormField>
    <UFormField label="通知方式">
      <ShuoCheckboxGroup
        v-model="form.notify"
        :items="notifyOptions"
        :skeleton="pending"
      />
    </UFormField>
    <UFormField label="附件">
      <ShuoFile v-model="form.file" :skeleton="pending" />
    </UFormField>
  </div>
</template>

<script setup lang="ts">
const types = ['一般', '急件'];
const notifyOptions = ['簡訊', 'Email', '電話'];
const form = reactive({
  name: '王小明',
  type: '一般',
  note: '骨架保留每個欄位原本的高度與寬度，資料回來後畫面不會跳動。',
  notify: ['Email'],
  file: null as File | null
});

// 模擬向後端重新取得資料：期間以骨架覆蓋，回來後填入新值。
const pending = ref(false);
const reload = async () => {
  pending.value = true;
  await new Promise((resolve) => setTimeout(resolve, 1500));
  Object.assign(form, {
    name: '陳美玲',
    type: '急件',
    note: '資料已重新載入。',
    notify: ['簡訊', '電話']
  });
  pending.value = false;
};
</script>

和 loading 的差別：loading 保留目前的值、在欄位內顯示轉圈圖示，適合欄位自己在處理（例如查詢下拉選項）；skeleton 蓋住整個欄位，適合整頁資料還沒回來、目前的值沒有意義的時候。

空值約定

父層綁定 null／undefined 時，下列元件會回寫約定空值；型別錯誤等非預期值也會清空為約定空值。掛載時與之後由父層回填皆適用。清空非預期值時，ShuoInputText、ShuoTextarea、ShuoInputNumber、ShuoRadioGroup、ShuoPhone、ShuoDatepicker 會以 console.warn（[Shuo元件名] … 已清空）留下紀錄；ShuoSelectMenu、ShuoMonths 只清空，不警告。

元件空值
ShuoInputText、ShuoTextarea、ShuoRadioGroup、ShuoPhone''
ShuoSelectMenuemptyValue（預設 ''）；多選 []
ShuoInputNumber、ShuoMonthsnull
ShuoDatepicker單選 ''、範圍 []

按「套用後端回傳的 null」，模擬後端把每個欄位都回傳 null，下方的綁定值會改成各元件約定的空值；ShuoCheckboxGroup 不回寫，維持 null。

  <ExampleOptions>
    <ExampleAction
      label="套用後端回傳的 null"
      icon="i-lucide-circle-slash"
      :action="applyNull"
    />
    <ExampleAction label="還原" icon="i-lucide-undo-2" :action="restore" />
  </ExampleOptions>

  <div class="grid gap-4 sm:grid-cols-2">
    <UFormField label="ShuoInputText → ''">
      <ShuoInputText v-model="form.text" />
    </UFormField>
    <UFormField label="ShuoInputNumber → null">
      <ShuoInputNumber v-model="form.amount" />
    </UFormField>
    <UFormField label="ShuoSelectMenu → ''">
      <ShuoSelectMenu v-model="form.type" :items="types" />
    </UFormField>
    <UFormField label="ShuoDatepicker → ''">
      <ShuoDatepicker v-model="form.date" />
    </UFormField>
    <UFormField label="ShuoCheckboxGroup（不回寫）">
      <ShuoCheckboxGroup v-model="form.days" :items="days" />
    </UFormField>
  </div>
  <!-- 以 JSON 顯示，才看得出空字串與 null 的差別 -->
  <p class="text-muted text-sm">綁定值：{{ JSON.stringify(form) }}</p>
</template>

<script setup lang="ts">
const types = ['一般', '急件'];
const days = ['週一', '週三', '週五'];
const initial = {
  text: '王小明',
  amount: 1200 as number | null,
  type: '一般',
  date: '2026/10/25',
  days: ['週一']
};
const form = reactive({ ...initial, days: [...initial.days] });

// 模擬後端把每個欄位都回傳成 null：元件會把綁定值改寫成各自約定的空值。
const applyNull = () => {
  const fromApi = {
    text: null,
    amount: null,
    type: null,
    date: null,
    days: null
  };
  Object.assign(form, fromApi);
};
const restore = () =>
  Object.assign(form, { ...initial, days: [...initial.days] });
</script>

下列元件不回寫父層的值：

  • ShuoCheckboxGroup：null 或非陣列值顯示為全部未勾選，勾選後回寫完整陣列；清空為 []。
  • ShuoCheckbox：綁定值不等於 trueValue 時顯示未勾選。
  • ShuoFile：清除後為 null。
