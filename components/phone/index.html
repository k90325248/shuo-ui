元件

Phone

UInput
市話號碼，兩個輸入框分別輸入區碼與電話。

v-model: string（完整號碼），另有 v-model:area-code、v-model:number，見下方 v-model。

用法

綁定

三個綁定同步更新，完整號碼為區碼加電話，不加分隔符號。按「讀取綁定值」以通知顯示目前的三個值。

<template>
  <ExampleOptions>
    <ExampleAction label="讀取綁定值" icon="i-lucide-eye" :action="show" />
  </ExampleOptions>
  <ShuoPhone
    v-model="full"
    v-model:area-code="areaCode"
    v-model:number="number"
  />
</template>

<script setup lang="ts">
// 三個綁定同步更新；區碼與電話合併成完整號碼，不加分隔符號。
const full = ref('0223456789');
const areaCode = ref('02');
const number = ref('23456789');
const toast = useToast();

const show = () => {
  toast.add({
    title: '綁定值',
    description: [
      `完整號碼 ${full.value}`,
      `區碼 ${areaCode.value}`,
      `電話 ${number.value}`
    ].join('，')
  });
};
</script>
  • 三者皆保留字串與開頭的 0，例如區碼 02、電話 00123456，完整號碼為 0200123456。
  • 使用者輸入或貼上時只保留半形數字；父層回填則原樣顯示，使用者編輯該欄後才過濾。
  • 區碼或電話型別不符時只清空該欄並重新合併完整號碼；完整號碼型別不符時兩欄一併清空。

只回填完整號碼

只回填完整號碼時，依已知且符合前綴的區碼拆分；沒有可用區碼則全文放入電話欄並清空區碼，不猜測長度。要拆成兩欄，請同時綁定 v-model:area-code 並給已知區碼。切換 area-code 比較兩種結果：

<template>
  <ExampleOptions>
    <ExampleOption
      v-model="known"
      label="area-code"
      :items="['02', '未提供']"
    />
  </ExampleOptions>
  <!-- 切換時重新掛載，模擬父層第一次回填 -->
  <ShuoPhone :key="known" v-model="full" v-model:area-code="areaCode" />
</template>

<script setup lang="ts">
const PHONE = '0223456789';

// 有已知區碼且符合前綴時拆成兩欄；沒有則全文放入電話欄。
const known = ref<'02' | '未提供'>('02');
const full = ref(PHONE);
const areaCode = ref('02');

watch(known, (value) => {
  full.value = PHONE;
  areaCode.value = value === '02' ? '02' : '';
});
</script>

外觀

沿用 UInput 的 color 與 highlight，同時套用到區碼與電話兩個輸入框。

<template>
  <ExampleOptions>
    <ExampleOption v-model="color" label="color" :items="colors" />
    <ExampleOption
      v-model="highlight"
      label="highlight"
      :items="[false, true]"
    />
  </ExampleOptions>
  <ShuoPhone v-model="phone" :color="color" :highlight="highlight" />
</template>

<script setup lang="ts">
type Color =
  | 'primary'
  | 'secondary'
  | 'success'
  | 'info'
  | 'warning'
  | 'error'
  | 'neutral';

const colors: Color[] = [
  'primary',
  'secondary',
  'success',
  'info',
  'warning',
  'error',
  'neutral'
];
const color = ref<Color>('primary');
const highlight = ref(false);
const phone = ref('');
</script>

尺寸與狀態

載入中在電話號碼欄最右側顯示轉圈圖示並停用兩欄；各狀態的共通行為見共用參數。

<template>
  <ExampleOptions>
    <ExampleOption v-model="size" label="size" :items="sizes" />
    <ExampleOption v-model="state" label="狀態" :items="states" />
  </ExampleOptions>
  <ShuoPhone
    v-model="phone"
    v-model:area-code="areaCode"
    :size="size"
    :loading="state === '載入中'"
    :disabled="state === '停用'"
    :skeleton="state === '骨架'"
  />
</template>

<script setup lang="ts">
type Size = 'xs' | 'sm' | 'md' | 'lg' | 'xl';

const sizes: Size[] = ['xs', 'sm', 'md', 'lg', 'xl'];
const states = ['一般', '停用', '載入中', '骨架'] as const;
const size = ref<Size>('lg');
const state = ref<(typeof states)[number]>('一般');
const phone = ref('0423456789');
const areaCode = ref('04');
</script>

範例

搭配表單驗證

元件不內建電話長度或區碼合法性規則，請由表單 schema 定義。範例以 requiredText 檢查必填，再以 v.regex 檢查完整號碼的格式。

<template>
  <UForm
    :schema="schema"
    :state="state"
    class="flex flex-col gap-4"
    @submit="onSubmit"
  >
    <UFormField label="聯絡電話" name="phone" required>
      <ShuoPhone v-model="state.phone" />
    </UFormField>
    <div>
      <UButton type="submit" label="送出" />
    </div>
  </UForm>
</template>

<script setup lang="ts">
import * as v from 'valibot';

// 元件不檢查長度與區碼，規則寫在 schema；這裡檢查完整號碼。
const schema = v.object({
  phone: v.pipe(
    requiredText('聯絡電話'),
    v.regex(/^0\d{8,9}$/, '聯絡電話 須為 0 開頭的 9～10 碼')
  )
});
const state = reactive({ phone: '' });
const toast = useToast();

const onSubmit = (event: { data: v.InferOutput<typeof schema> }) => {
  toast.add({ title: '送出成功', description: event.data.phone });
};
</script>

區碼與電話分開儲存

後端以兩個欄位儲存時，只綁 v-model:area-code 與 v-model:number。按「載入資料」模擬向後端取資料，期間以 loading 停用輸入。

<template>
  <ExampleOptions>
    <ExampleAction label="載入資料" icon="i-lucide-refresh-cw" :action="load" />
  </ExampleOptions>
  <UForm :state="state" class="flex flex-col gap-4" @submit="onSubmit">
    <UFormField label="公司電話">
      <ShuoPhone
        v-model:area-code="state.areaCode"
        v-model:number="state.number"
        :loading="loading"
      />
    </UFormField>
    <div>
      <UButton type="submit" label="送出" />
    </div>
  </UForm>
</template>

<script setup lang="ts">
// 後端分兩欄儲存區碼與電話時，只綁 area-code 與 number。
const state = reactive({ areaCode: '', number: '' });
const loading = ref(false);
const toast = useToast();

// 模擬向後端取得資料。
const load = async () => {
  loading.value = true;
  await new Promise((resolve) => setTimeout(resolve, 800));
  Object.assign(state, { areaCode: '049', number: '2345678' });
  loading.value = false;
};

const onSubmit = () => {
  toast.add({
    title: '送出成功',
    description: `區碼 ${state.areaCode}，電話 ${state.number}`
  });
};
</script>

v-model型別說明
v-modelstring完整號碼（區碼加號碼，無分隔符號）
v-model:area-codestring區碼
v-model:numberstring電話號碼

—見樣式

size、disabled、loading、skeleton、name 的行為見共用參數；id 指向區碼框。

樣式

ui 合併規則見單一元件的 ui prop；areaCode、number 的值同 Nuxt UI UInput 的 ui：

Slot部位內建樣式
root外層flex w-full min-w-0 items-center gap-2，字級依尺寸
areaCode區碼輸入框root 容納三位數、最多佔一半寬度；base 為 text-center tabular-nums
number電話號碼輸入框root 為 min-w-0 flex-1；base 為 tabular-nums
<ShuoPhone
  v-model="fullPhone"
  class="w-72"
  :ui="{ areaCode: { root: 'w-20' } }"
/>

外層的 class 與 ui.root 一起合併，可覆寫寬度。
