元件

QueryCard

UCardUForm
可收合的查詢條件卡片，內含 UForm，欄位以響應式格線排列。

欄位以響應式格線排列（一欄、md 兩欄、xl 四欄，可由 ui.grid 調整），在欄位內按 Enter 即可送出。泛型 S 為 schema。

用法

在欄位內按 Enter 即可送出；驗證失敗時，收合狀態下會自動展開以顯示錯誤訊息。透過 template ref 可呼叫 submit()、clear()，例如由卡片外的按鈕觸發查詢；停用時兩者皆不動作。

查詢條件

送出的資料：尚未查詢

query-card-basic.vue
<template>
  <ShuoQueryCard :state="query" :schema="schema" @submit="onSubmit" @clear="onClear">
    <UFormField label="姓名" name="name" required>
      <ShuoInputText v-model="query.name" />
    </UFormField>
    <UFormField label="類別" name="type">
      <ShuoSelectMenu v-model="query.type" :items="['一般', '急件']" placeholder="全部" />
    </UFormField>
    <UFormField label="申請日期" name="date">
      <ShuoDatepicker v-model="query.date" clearable />
    </UFormField>
    <template #actions="{ clear }">
      <UButton label="清除" color="neutral" variant="soft" @click="clear" />
      <UButton type="submit" label="查詢" />
    </template>
  </ShuoQueryCard>
  <p class="text-muted text-sm">送出的資料：{{ submitted ?? '尚未查詢' }}</p>
</template>

<script setup lang="ts">
import * as v from 'valibot';

const schema = v.object({
  name: requiredText('姓名'),
  type: v.string(),
  date: v.string()
});
const query = reactive({ name: '', type: '', date: '' });
const submitted = ref<v.InferOutput<typeof schema>>();

// 驗證通過才會觸發 submit；清除時由頁面重設資料，元件再清除驗證錯誤。
const onSubmit = (event: { data: v.InferOutput<typeof schema> }) => (submitted.value = event.data);
const onClear = () => {
  Object.assign(query, { name: '', type: '', date: '' });
  submitted.value = undefined;
};
</script>

欄數

改欄數時要寫齊各斷點：tailwind-merge 只會取代同一斷點的 class，只傳 md:grid-cols-3 時，內建的 xl:grid-cols-4 仍會生效。

<!-- md 起三欄 -->
<ShuoQueryCard :state="query" :ui="{ grid: 'md:grid-cols-3 xl:grid-cols-3' }">...</ShuoQueryCard>

<!-- 函式寫法：移除內建斷點後自訂 -->
<ShuoQueryCard
  :state="query"
  :ui="{ grid: (defaults) => defaults.replace(/(md|xl):grid-cols-\d/g, '') + ' lg:grid-cols-3' }"
>
  ...
</ShuoQueryCard>

全站統一欄數見查詢欄位分欄。

長標題

標題預設不換行、不省略；header-right 放不下時整塊換到下一行並靠右，不會擠壓標題與收合按鈕。ShuoListCard 的標題列使用相同規則。要讓長標題在圖示旁換行，覆寫標題列不換行並允許標題收縮：

<ShuoQueryCard :state="query" :ui="{ bar: 'flex-nowrap', title: 'min-w-0 shrink whitespace-normal' }">
  ...
</ShuoQueryCard>

樣式
