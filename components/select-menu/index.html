元件

SelectMenu

USelectMenu
下拉選單，可搜尋、多選，文字過長時顯示完整提示。

基於 USelectMenu，帶有搜尋與省略提示。單選 v-model 為選項的 value，多選為 value 陣列。

用法

單選與多選

單選綁定選項的 value；multiple 時綁定 value 陣列。單選未選取時為 emptyValue（預設 ''），多選為 []。

綁定值：general／[ "general", "notice" ]

select-menu-basic.vue
<template>
  <UFormField label="單選">
    <ShuoSelectMenu v-model="type" :items="items" placeholder="請選擇" />
  </UFormField>
  <UFormField label="多選">
    <ShuoSelectMenu v-model="types" :items="items" multiple placeholder="請選擇" />
  </UFormField>
  <p class="text-muted text-sm">綁定值：{{ type }}／{{ types }}</p>
</template>

<script setup lang="ts">
const items = [
  { label: '一般公告', value: 'general' },
  { label: '系統公告', value: 'system' },
  { label: '作業通知', value: 'notice' }
];
const type = ref('general');
const types = ref<string[]>(['general', 'notice']);
</script>

顯示格式

預設只顯示名稱。{value}、{label} 會被替換，替換結果不再二次解析，未知標記原樣保留。關鍵字查詢依 labelKey 欄位比對，不受顯示格式影響。

select-menu-format.vue
<template>
  <UFormField label="預設：只顯示名稱">
    <ShuoSelectMenu v-model="code" :items="items" />
  </UFormField>
  <UFormField label='format="{value}_{label}"'>
    <ShuoSelectMenu v-model="code" :items="items" format="{value}_{label}" />
  </UFormField>
  <UFormField label='format="{label}（{value}）"'>
    <ShuoSelectMenu v-model="code" :items="items" format="{label}（{value}）" />
  </UFormField>
</template>

<script setup lang="ts">
const items = [
  { label: '一般件', value: 'N01' },
  { label: '急件', value: 'U02' },
  { label: '特急件', value: 'S03' }
];
const code = ref('U02');
</script>

要讓整個專案都顯示「值_名稱」，在全站設定 format：

<ShuoSelectMenu v-model="state.type" :items="items" format="{value}_{label}" />

// nuxt.config.ts
export default defineNuxtConfig({
  shuoUi: {
    components: {
      selectMenu: { format: '{value}_{label}' }
    }
  }
});

自訂選項欄位

後端欄位不是 label、value 時，以 label-key、value-key 指定。USelectMenu 的 description-key 等 props 也能直接使用，欄位名稱依 items 推導，寫錯會有型別錯誤。

綁定值：TXG

select-menu-keys.vue
<template>
  <ShuoSelectMenu v-model="branch" :items="branches" label-key="Name" value-key="Code" description-key="Address" />
  <p class="text-muted text-sm">綁定值：{{ branch }}</p>
</template>

<script setup lang="ts">
// 後端回傳的欄位名稱不是 label、value 時，以 label-key、value-key 指定，不必先轉換資料。
const branches = [
  { Code: 'TPE', Name: '台北分行', Address: '台北市中正區' },
  { Code: 'TXG', Name: '台中分行', Address: '台中市西區' },
  { Code: 'KHH', Name: '高雄分行', Address: '高雄市前金區' }
];
const branch = ref('TXG');
</script>

載入中、停用與骨架

切換骨架、停用或載入中時會關閉已開啟的選單，還原後不自動重開。

select-menu-states.vue
<template>
  <div class="flex flex-wrap gap-4">
    <USwitch v-model="loading" label="載入中" />
    <USwitch v-model="disabled" label="停用" />
    <USwitch v-model="skeleton" label="骨架" />
  </div>
  <ShuoSelectMenu
    v-model="type"
    :items="['一般公告', '系統公告', '作業通知']"
    :loading="loading"
    :disabled="disabled"
    :skeleton="skeleton"
  />
</template>

<script setup lang="ts">
const type = ref('一般公告');
const loading = ref(false);
const disabled = ref(false);
const skeleton = ref(false);
</script>

Slots

USelectMenu 的 slot 全部可用（leading、trailing、item、item-leading、content-top 等）。以下三個有傳入時取代元件的內建內容：

Slot內建內容
item-label依 format 格式化的選項文字
default依 format 格式化的已選取文字
empty「無可用選項」

Expose

名稱型別說明
triggerRefHTMLButtonElement觸發按鈕
viewportRefHTMLDivElement | null選單捲動區域

樣式

ui 可用 Nuxt UI USelectMenu 的所有 slot，另外提供 wrapper：

Slot部位內建樣式
wrapper外層，量測省略文字並掛 Tooltipflex w-full min-w-0
base觸發按鈕（Nuxt UI）w-full min-w-0
value、placeholder已選取文字、提示文字（Nuxt UI）min-w-0 truncate

要縮短寬度時設定 ui.wrapper（例如 w-40），觸發按鈕會填滿外層；class 落在觸發按鈕，不影響外層。ui.value、ui.placeholder 在已選取、未選取與找不到選項時都套用。
