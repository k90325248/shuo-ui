元件

Table

UTable
基於 UTable 的純表格，含骨架、空資料與高度過渡。

沒有卡片、標題與分頁，可直接放進彈窗或自己的 UCard。共用的表頭不換行、儲存格內距、空資料與查詢中文字、初次載入骨架、interactionDisabled，以及高度與淡化過渡。泛型 T 為資料列型別。

用法

查詢中與空資料

元件建立時即在查詢且沒有資料時顯示骨架列；已有資料時重新查詢，資料淡化並以高度過渡切換。清空資料後顯示「查無資料」。

項目金額
房屋貸款3,200,000
信用貸款450,000
汽車貸款680,000
table-basic.vue
<template>
  <div class="flex flex-wrap gap-2">
    <UButton label="重新查詢" size="sm" variant="outline" :loading="loading" @click="reload" />
    <UButton label="清空資料" size="sm" variant="ghost" color="neutral" @click="rows = []" />
  </div>
  <ShuoTable :data="rows" :columns="columns" :loading="loading" />
</template>

<script setup lang="ts">
import type { TableColumn } from '@nuxt/ui';

interface Row {
  item: string;
  amount: string;
}

const columns: TableColumn<Row>[] = [
  { accessorKey: 'item', header: '項目' },
  { accessorKey: 'amount', header: '金額' }
];
const source: Row[] = [
  { item: '房屋貸款', amount: '3,200,000' },
  { item: '信用貸款', amount: '450,000' },
  { item: '汽車貸款', amount: '680,000' }
];
const rows = ref<Row[]>([...source]);
const loading = ref(false);

// 重新查詢且已有資料時，資料淡化並以高度過渡切換到新內容。
const reload = async () => {
  loading.value = true;
  await new Promise((resolve) => setTimeout(resolve, 800));
  rows.value = source.slice(0, Math.floor(Math.random() * 3) + 1);
  loading.value = false;
};
</script>

可編輯表格

在 cell slot 放 Shuo 輸入元件，搭配 UCard 的標題與底部按鈕。

理財目標
目標金額
元
table-editable.vue
<template>
  <UCard :ui="{ body: 'p-0 sm:p-0' }">
    <template #header>理財目標</template>
    <ShuoTable :data="goals" :columns="columns">
      <template #目標-cell="{ row }">
        <ShuoInputText v-model="row.original.目標" class="min-w-20" />
      </template>
      <template #金額-cell="{ row }">
        <ShuoInputNumber v-model="row.original.金額" unit class="min-w-28" />
      </template>
    </ShuoTable>
    <template v-if="goals.length < 5" #footer>
      <UButton label="新增一筆" size="sm" variant="soft" @click="goals.push({ 目標: '', 金額: null })" />
    </template>
  </UCard>
</template>

<script setup lang="ts">
import type { TableColumn } from '@nuxt/ui';

interface Goal {
  目標: string;
  金額: number | null;
}

const columns: TableColumn<Goal>[] = [
  { accessorKey: '目標', header: '目標' },
  { accessorKey: '金額', header: '金額' }
];
const goals = ref<Goal[]>([{ 目標: '購屋頭期款', 金額: 2000000 }]);
</script>

彈窗內的明細表

限制高度並固定表頭時，用 tableProps 設定 ui.root 與 sticky，捲動發生在表格本身，表頭才會固定。

<ShuoTable :data="rows" :columns="columns" :loading="!rows" :table-props="{ sticky: true, ui: { root: 'max-h-80' } }" />

過渡

資料筆數或內容高度改變時，資料區高度以 0.2 秒平滑變化；重新查詢且已有資料時，資料淡化為 0.5。transition 設為 false 時高度直接跟著內容，淡化不播放過渡。使用者偏好減少動態效果時一律不播放。
