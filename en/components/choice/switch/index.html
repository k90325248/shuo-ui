Switch

USwitch
A switch that can run an action after toggling, updating only on success and reverting on failure.

v-model: boolean | string | number, boolean by default. Apart from action and label truncation, its props, events and slots are the same as USwitch.

Usage

Label and description

label is the text next to the switch and description the text below it. It shows on one line and is truncated when wider than its container. A tooltip shows the full text on hover or focus, or on long press on touch devices (see Tooltip), the same as the checkbox. The description wraps: without one the height matches an input, and with one the switch grows while its first line still lines up with fields next to it.

Case statistics for the previous week every Monday; turn it off at any time

<template>
  <div class="flex w-72 flex-col gap-2">
    <ShuoSwitch v-model="notify" label="Enable notifications" />
    <!-- Labels wider than the space are truncated; hover to see the full text -->
    <ShuoSwitch
      v-model="email"
      label="Email the case officer when there is a new application"
    />
    <!-- Grows with a description that wraps -->
    <ShuoSwitch
      v-model="digest"
      label="Weekly digest"
      description="Case statistics for the previous week every Monday; turn it off at any time"
    />
  </div>
</template>

<script setup lang="ts">
const notify = ref(true);
const email = ref(false);
const digest = ref(true);
</script>

Action

action runs after toggling, receives the new value and may return a Promise. Use it for settings that are saved through an API as soon as they change, such as enabling an account or notifications.

<template>
  <ExampleOptions>
    <ExampleOption
      v-model="result"
      label="Result"
      :items="['Success', 'Failure']"
    />
  </ExampleOptions>
  <ShuoSwitch v-model="enabled" label="Enable account" :action="save" />
</template>

<script setup lang="ts">
const enabled = ref(false);
const result = ref('Success');
const toast = useToast();

// Mock API call: on failure, notify and return false so the switch reverts.
const save = async (value: boolean | string | number) => {
  try {
    await new Promise((resolve, reject) =>
      setTimeout(
        () => (result.value === 'Success' ? resolve(true) : reject()),
        800
      )
    );
    toast.add({ title: value ? 'Enabled' : 'Disabled' });
    return true;
  } catch {
    toast.add({ color: 'error', title: 'Could not save, please try again' });
    return false;
  }
};
</script>
StageSwitchv-modelchange event
PendingShows the new value, loading and disabledUnchangedNot emitted
SuccessKeeps the new value, loading and disabled endUpdated to the new valueEmitted
FailureGoes back to the old value, loading and disabled endUnchangedNot emitted
ErrorSame as failureUnchangedNot emitted
  • Success: only returning false (or a Promise resolving to false) counts as a failure. Any other value is a success, including no return value as in async () => { await save(value) }.
  • Errors: when the action throws, the switch reverts the same way and the error is thrown again, for the global error handler or the console. To notify the user, try/catch inside the action, show a message and return false, as in the example above.
  • Pending: the switch is disabled, so the action is not called twice. If the page changes v-model while pending, the page's value wins and is not overwritten when the action finishes.
  • Without action, v-model updates right after toggling, the same as USwitch.

The SwitchAction and SwitchValue types can be imported from #shuo-ui/components/ShuoSwitch.vue.

On and off values

true-value and false-value are the bound values when on and off, true and false by default. Change them when the back end uses Y/N; the action receives these values too.

<template>
  <ShuoSwitch
    v-model="status"
    label="Public"
    true-value="Y"
    false-value="N"
    @change="toast.add({ title: `Bound value: ${status}` })"
  />
</template>

<script setup lang="ts">
const status = ref('N');
const toast = useToast();
</script>

Size and states

When size is not set, it follows the UFormField size and the site-wide setting, lg built in, the same as the other input components. Without a description, the switch height matches an input of the same size (24 to 40px for xs to xl), so it lines up with other fields in the same row. loading shows a loading icon and disables the switch; disabled follows the form state when not set; skeleton covers it with a skeleton of the same size. See Common props for the shared behavior of the states.

<template>
  <ExampleOptions>
    <ExampleOption
      v-model="size"
      label="size"
      :items="['xs', 'sm', 'md', 'lg', 'xl']"
    />
    <ExampleOption v-model="disabled" label="disabled" :items="[true, false]" />
    <ExampleOption v-model="loading" label="loading" :items="[true, false]" />
  </ExampleOptions>
  <ShuoSwitch
    v-model="enabled"
    label="Auto renewal"
    :size="size"
    :disabled="disabled"
    :loading="loading"
  />
</template>

<script setup lang="ts">
const enabled = ref(true);
const size = ref<'xs' | 'sm' | 'md' | 'lg' | 'xl'>('lg');
const disabled = ref(false);
const loading = ref(false);
</script>

size, color and loadingIcon can be set site-wide with components.switch in Component defaults.

Examples

Loading state on buttons

Buttons need no wrapper: with loading-auto, UButton shows loading and is disabled until the Promise returned by @click settles.

<UButton label="Save" loading-auto @click="save" />

Styling

ui accepts every slot of Nuxt UI USwitch, merged as described in Per-component ui prop; wrapper is the component's own outer wrapper instead:

SlotPartBuilt-in style
wrapperOuter wrapper that measures truncation and holds the tooltipinline-flex w-fit max-w-full min-w-0 align-top
rootSwitch box (Nuxt UI)w-fit max-w-full min-w-0, height matching an input of the same size, centered
labelLabel (Nuxt UI)block truncate

You can also adjust the height with class="[--form-switch-height:1.25rem]". class goes on the switch box, not the outer wrapper. Inside a flex container, the wrapper shrinks with the available space and truncates the label; set ui.wrapper to shrink-0 to show the full label.
