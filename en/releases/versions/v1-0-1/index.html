v1.0.1

View on GitHub
Released on October 25, 2026

1.0.0 failed to build in projects without @iconify-json/lucide and has been withdrawn; use 1.0.1 instead. This release is the first stable version and includes the fix below.

The first stable release of Shuo UI: Nuxt UI components shaped around the way our projects write forms, shipped as a Nuxt module with 15 components. See the docs site for full guides and live examples.

✨ Highlights

🧩 Built on Nuxt UI

The components wrap Nuxt UI. Nuxt UI props, slots and refs that are not redeclared can be used directly, with types inferred, so you can follow the Nuxt UI docs: Built on Nuxt UI

<ShuoInputText v-model="keyword" variant="soft" icon="i-lucide-search" />

🇹🇼 Traditional Chinese and Taiwanese formats

Texts default to Traditional Chinese, with formats common in our projects built in: masked ID numbers, thousands separators, ROC-year dates, area codes and phone numbers, and year/month conversion. Bound values keep the raw data (Gregorian dates, plain numbers) and are only converted for display.

<ShuoInputText v-model="idNumber" :mask="4" />
<ShuoInputNumber v-model="amount" unit />
<!-- Shows 115/10/25; the bound value is 2026/10/25 -->
<ShuoDatepicker v-model="applyDate" />

📐 Consistent sizes and states

All form inputs share size, disabled, loading, skeleton, id and name. Components of the same size have the same height and follow the size, disabled and error states of UFormField and UForm: Shared props

<UForm :schema="schema" :state="state" :disabled="saving">
  <UFormField label="Amount" name="amount" size="md">
    <ShuoInputNumber v-model="state.amount" :skeleton="loading" />
  </UFormField>
</UForm>

⚙️ Site-wide defaults and shared validation rules

Sizes, display formats, icons and more can be set once in nuxt.config.ts, while values passed on a component still win. Common Valibot rules are auto-imported, with consistent error messages across the site: Component defaults, Validation

export default defineNuxtConfig({
  modules: ['@nuxt/ui', '@shuo/ui'],
  shuoUi: {
    components: {
      selectMenu: { format: '{value}_{label}' },
      listCard: { pageSize: 20 }
    }
  }
});

const schema = v.object({
  name: requiredText('Name'),
  amount: requiredNumber('Amount')
});

🔎 Query page layout

ShuoQueryCard holds the query fields and ShuoListCard the results with server-side pagination, with loading skeletons, empty data and height transitions handled: QueryCard, ListCard

🚀 New components

  • InputText: Single-line text input that can mask all or the last characters (docs)
  • InputNumber: Number input with thousands separators after blur, configurable decimals and unit (docs)
  • Textarea: Multi-line text input that keeps line breaks and can resize automatically (docs)
  • SelectMenu: Select menu with search and multiple selection, showing the full text when truncated (docs)
  • Datepicker: Date picker with ROC years by default, five precisions and range selection (docs)
  • Checkbox: Single checkbox with custom checked values and content next to the label (docs)
  • RadioGroup: Radio group that lays out by viewport width, with custom item fields and item content (docs)
  • CheckboxGroup: Checkbox group that lays out by viewport width, with custom item fields and item content (docs)
  • File: Single file selection and download of an existing attachment; selecting does not upload (docs)
  • Months: Year and month input that can bind the total months, years and months at once (docs)
  • Phone: Landline number with separate inputs for the area code and number (docs)
  • QueryCard: Collapsible query card with a UForm inside and fields on a responsive grid (docs)
  • ListCard: Results card with a title bar, table and server-side pagination (docs)
  • Table: Plain table based on UTable, with skeletons, empty data and height transitions (docs)
  • InfoTooltip: Info icon with a tooltip shown on hover or keyboard focus (docs)

🐛 Bug Fixes

  • module: Only icons from installed icon collections are added to the @nuxt/icon client bundle. 1.0.0 always added the built-in lucide icons, so nuxt build and nuxt generate failed to create the client bundle in projects without @iconify-json/lucide. Projects without it now build, and icons are loaded by @nuxt/icon at runtime. Installing @iconify-json/lucide is still recommended so icons are bundled into the site.

⚠️ Before you start

  • Checkboxes and choice groups (ShuoCheckbox, ShuoRadioGroup, ShuoCheckboxGroup) match the height of inputs, so they do not support Nuxt UI descriptions (description, descriptionKey), variant (card, table), indicator or highlight. Passing them is a type error and they are not applied at runtime.
  • ShuoInputNumber has no native min, max or step; use validation rules for ranges.
  • Selecting a file does not upload it: ShuoFile only handles selection and download, and the page decides when to upload.

📦 Installation

pnpm add github:k90325248/shuo-ui#v1.0.1
pnpm add @iconify-json/lucide # recommended, icons are bundled

Enable the module in nuxt.config.ts and add @import '@shuo/ui/css'; to your CSS; see Installation on the docs site.
