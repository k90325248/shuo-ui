# v1.1.0

> Released on October 26, 2026

Adds `ShuoTooltip`, so every tooltip can be shown with a long press on phones; component texts now follow the Nuxt UI locale, with Traditional Chinese and English built in. The docs site gains an English version and is reorganized into tabs and groups. Before upgrading, read "Upgrade notes" below: the auto-imported functions and the locale behavior of component texts have changed.

## ✨ Highlights

### 📱 Long press for tooltips on phones

Nuxt UI's `UTooltip` only opens on hover or keyboard focus, so tapping or holding on a phone shows nothing. The new `ShuoTooltip` keeps all `UTooltip` props and slots and adds long press on touch devices. `ShuoInfoTooltip` and the truncated-text tooltips of the select menu, datepicker, file, checkbox and choice groups all use it, so they also open with a long press on phones: [Tooltip](https://k90325248.github.io/shuo-ui/components/helper/tooltip)

```vue
<ShuoTooltip text="Save draft">
  <UButton label="Save" />
</ShuoTooltip>
```

A long press that shows a tooltip does not trigger the original click, check or menu. To keep Nuxt UI's original behavior, pass `:touch="false"` on a component or set `components.tooltip.touch: false` site-wide.

### 🌐 Component texts follow the Nuxt UI locale

Validation messages, accessible names, tooltips, and the months and weekdays of the datepicker follow `<UApp :locale>`, with Traditional Chinese and English built in; mounted components update immediately. Texts can be overridden per locale, and other locales can be added: [Locales and messages](https://k90325248.github.io/shuo-ui/getting-started/theme/messages)

```ts
export default defineNuxtConfig({
  shuoUi: {
    locale: 'zh-TW', // used when the page does not set a UApp locale
    locales: {
      en: { listCard: { title: 'Search results' } }
    }
  }
});
```

### 🌙 Form color tokens for dark mode

Disabled inputs in dark mode now use a darker background and lighter text instead of the light mode colors, and input borders use a lighter primary color. The disabled color also changed from a fixed gray to Nuxt UI's neutral color, following `ui.colors.neutral` in your `app.config.ts`. The colors come from the `--ui-form-*` variables, which you can override in your CSS for `:root` and `.dark`: [Form color tokens](https://k90325248.github.io/shuo-ui/getting-started/theme/theming#form-color-tokens)

## 🚀 New components

- **Tooltip:** Tooltip based on UTooltip that also opens with a long press on touch devices ([docs](https://k90325248.github.io/shuo-ui/components/helper/tooltip))

## 🐛 Bug Fixes

- **InputText:** Revealing masked text no longer briefly flashes the whole value.
- **Months:** The year and month units grow with their text, so the English `yr` and `mo` are no longer cut off.

## ⚠️ Upgrade notes

Internal functions such as `getShuoMessages`, `setShuoMessages`, `formatMessage`, `toNumberText`, `getDecimalPlaces`, `filterPhoneInput`, `getDateModelFormat`, `isValidDateSeparator`, `useChoiceGroup` and `useTruncatedText` are no longer auto-imported. If your project uses them, the build reports missing functions. They are not public API and may change, so use the public functions above or module options instead (for example, override texts with `shuoUi.messages` or `shuoUi.locales`).

### Component texts follow the UApp locale

Component texts used to be fixed to Traditional Chinese. Components now follow `<UApp :locale>`:

- Projects without a `UApp` `locale`, or with Traditional Chinese, look the same as before.
- Projects with another locale (for example English) will see component texts in that locale after upgrading. To adjust the wording, override it per locale with `shuoUi.locales`; see [Locales and messages](https://k90325248.github.io/shuo-ui/getting-started/theme/messages#overriding-messages).

## 📖 Docs site

- **English version:** Switch between Traditional Chinese and English at the top right. URLs are now `/zh-tw/...` and `/en/...`, and the root URL redirects to the language you chose last. The 1.0.1 page URLs are no longer used; start again from the [home page](https://k90325248.github.io/shuo-ui/).
- **Tabs and groups:** Content is split into Getting started, Components and Utilities tabs, with the left menu grouped by purpose.
- **Theme menu:** The palette at the top right switches the primary color, font, radius, component size, ROC/Gregorian years and component locale on the fly, and exports the matching `app.config.ts`, CSS and `nuxt.config.ts`.

## 📦 Installation

```bash
pnpm add github:k90325248/shuo-ui#v1.1.0
pnpm add @iconify-json/lucide # recommended, icons are bundled
```

Enable the module in `nuxt.config.ts` and add `@import '@shuo/ui/css';` to your CSS; see [Installation](https://k90325248.github.io/shuo-ui/getting-started/overview/installation) on the docs site.
