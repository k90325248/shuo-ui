# v1.2.1

> Released on October 27, 2026

The docs site adds an "Agents" group so AI tools such as Cursor and Claude Code can use Shuo UI correctly: LLMs.txt, and a Shuo UI skill you can install directly. No components changed; upgrading from 1.2.0 needs no code changes.

## ✨ Highlights

### 🤖 A skill for AI tools

The new `shuo-ui` skill teaches AI coding agents to build forms and query pages with Shuo UI: the v-model types and empty values of each component, validation with `UForm` and Valibot, the query card with a paginated list card, the `shuoUi` site-wide settings and more. Once installed, type `/shuo-ui` in your agent's chat to invoke it: [Skills](https://k90325248.github.io/shuo-ui/getting-started/agents/skills)

```bash
npx skills add k90325248/shuo-ui
```

- Cursor can install it with one click from the "Install Skill" button on the docs page, Claude Code uses `claude skill add`, and other tools can reference `skills/shuo-ui/SKILL.md` on GitHub directly.
- The skill files live in `skills/shuo-ui` of the public repo and are also published at `/.well-known/skills/` on the docs site. The package does not include them, so what you install is the same as 1.2.0.

### 📄 LLMs.txt

The docs site provides [`/llms.txt`](https://k90325248.github.io/shuo-ui/llms.txt) (an index of every page) and [`/llms-full.txt`](https://k90325248.github.io/shuo-ui/llms-full.txt) (the full documentation), and every page has a markdown version: add `.md` to its URL. Give these URLs to tools such as ChatGPT or Claude so they answer from the docs: [LLMs.txt](https://k90325248.github.io/shuo-ui/getting-started/agents/llms-txt)

## 📖 Docs site

- **New pages:** Getting started has a new Agents group with [LLMs.txt](https://k90325248.github.io/shuo-ui/getting-started/agents/llms-txt) and [Skills](https://k90325248.github.io/shuo-ui/getting-started/agents/skills).

## 📦 Installation

```bash
pnpm add github:k90325248/shuo-ui#v1.2.1
pnpm add @iconify-json/lucide # recommended, icons are bundled
```

Enable the module in `nuxt.config.ts` and add `@import '@shuo/ui/css';` to your CSS; see [Installation](https://k90325248.github.io/shuo-ui/getting-started/overview/installation) on the docs site.
