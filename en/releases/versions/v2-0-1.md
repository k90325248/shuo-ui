# v2.0.1

> Released on November 2, 2026

Fixes the bottom of `ShuoTable` being cut off inside modals and other containers with a scale animation. Upgrading from 2.0.0 needs no code changes.

## 🐛 Bug Fixes

- **ShuoTable cut off at the bottom inside a modal:** when the table mounted during the `UModal` open animation (scale 0.95 → 1), the data area measured the scaled-down height and never corrected it after the animation, so the last row was only half visible when scrolled to the bottom. The table now measures its layout height, which CSS transforms do not affect; tables inside a `Popover` or a custom scale animation are fixed too. Pages that worked around this with `:transition="false"` can drop it after upgrading.

## 📦 Installation

```bash
pnpm add github:k90325248/shuo-ui#v2.0.1
pnpm add @iconify-json/lucide # recommended, icons are bundled
```

Enable the module in `nuxt.config.ts` and add `@import '@shuo/ui/css';` to your CSS; see [Installation](https://k90325248.github.io/shuo-ui/getting-started/overview/installation) on the docs site.
