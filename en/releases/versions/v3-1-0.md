# v3.1.0

> Released on November 5, 2026

The number input adds step buttons; the date picker can set the first day of the week, show the weekday in the input and use a separate display separator; the radio group adds a card appearance. Without the new props everything works as in 3.0.0, so upgrading needs no code changes.

## ✨ Highlights

### ➕ Number input: step buttons

`ShuoInputNumber` adds `buttons` (off by default), `step` (`1` by default), `min`, `max` and `orientation` (`horizontal` puts decrement left and increment right; `vertical` stacks both on the right). Arrow keys step once, PageUp / PageDown step 10 times, Home / End jump to `min` / `max`, and holding a button keeps stepping. Steps are computed in decimal, so repeatedly adding `0.25` has no floating-point error. From an empty value both buttons start at `min` (or `0`), and each step triggers form validation: [Step buttons in InputNumber](https://k90325248.github.io/shuo-ui/components/text/input-number#step-buttons)

```vue
<ShuoInputNumber v-model="hours" buttons :step="0.25" :min="0.25" :max="24" :decimal="2" unit="hr" />
```

`min` and `max` only limit the buttons and keys; typed values outside the range are not corrected, so keep validating ranges in the schema. To show the buttons across the project, set the site-wide default `components.inputNumber.buttons: true`. Without `buttons`, `step`, `min` or `max`, the arrow keys and layout are the same as in 3.0.0.

### 📅 Date picker: week start

`ShuoDatepicker` adds `week-start` (`0` is Sunday, `1` is Monday, and so on; `0` by default). The weekday header and the six-week grid both start from that day, and ranges, `min-date` and `max-date` behave the same. The value can change at any time and an already mounted component applies it the next time the calendar opens, so users can switch between Monday and Sunday on a settings page: [Week start and weekday display in Datepicker](https://k90325248.github.io/shuo-ui/components/date/datepicker#week-start-and-weekday-display)

```vue
<ShuoDatepicker v-model="date" :week-start="settings.weekStart" />
```

It can also be set site-wide; an explicit prop wins:

```ts
export default defineNuxtConfig({
  shuoUi: {
    components: {
      datepicker: { weekStart: 1 }
    }
  }
});
```

### 🗓️ Date picker: weekday in the input

`show-weekday` appends the weekday to the date, for example "2026/11/05 (Thu)", or "2026/11/05（星期四）" in Traditional Chinese; display only, `v-model` does not change. It applies to `date`, `datetime` and `datetime-second` (the time follows the weekday), `year` and `month` ignore it, and each end of a range shows its own. Override the format and names with `messages.datepicker.weekday` and `weekdays`, or set `components.datepicker.showWeekday` site-wide.

```vue
<ShuoDatepicker v-model="date" show-weekday :roc="false" separator="-" display-separator="-" />
```

### ➖ Date picker: display separator

`display-separator` sets the separator of the date shown in the input (`/` by default). `separator` still only decides the bound value's format, so the two are set separately: the example above binds `2026-11-05` and shows "2026-11-05 (Thu)". Without `display-separator` the display still uses slashes, as in 3.0.0. Year and year-month modes follow the message formats. A Gregorian-year project can set it once site-wide:

```ts
export default defineNuxtConfig({
  shuoUi: {
    components: {
      datepicker: { roc: false, separator: '-', displaySeparator: '-' }
    }
  }
});
```

### 🃏 Radio group: card appearance

`ShuoRadioGroup` adds `variant` (`list`, `card`) and `indicator` (`start`, `end`, `hidden`), which work with every `orientation` (including `grid` and `auto`), `label-key` / `value-key` / `description-key` and `#item-append`. Horizontal cards shrink when space runs out, truncating long text with the full text in a Tooltip; vertical and `grid` cards fill the width. Form errors, disabled items and keyboard focus all have matching card styles. New `#label` and `#description` slots let you put custom content in a card: [Card appearance in RadioGroup](https://k90325248.github.io/shuo-ui/components/choice/radio-group#card-appearance)

```vue
<ShuoRadioGroup
  v-model="theme"
  :items="themes"
  variant="card"
  orientation="grid"
  indicator="hidden"
  :ui="{ fieldset: 'grid-cols-3', item: 'min-w-0', wrapper: 'w-full', description: 'w-full' }"
>
  <template #description="{ item }">
    <ThemePreview :theme="item.value" />
  </template>
</ShuoRadioGroup>
```

Checkboxes and checkbox groups still do not support `variant` or `indicator`; the radio group does not support Nuxt UI's `table` or `highlight`.

## 📖 Docs site

- The InputNumber page adds a [Step buttons](https://k90325248.github.io/shuo-ui/components/text/input-number#step-buttons) section (hours, time entry ID and minutes examples) and an example with validation; the earlier "no `min` or `max`" tip is removed.
- The Datepicker page adds a [Week start and weekday display](https://k90325248.github.io/shuo-ui/components/date/datepicker#week-start-and-weekday-display) section, and [ROC years and separators](https://k90325248.github.io/shuo-ui/components/date/datepicker#roc-years-and-separators) adds `display-separator`.
- The RadioGroup page adds [Card appearance](https://k90325248.github.io/shuo-ui/components/choice/radio-group#card-appearance), card grid and custom card content examples, and the Slots table adds `label` and `description`.
- The [Component defaults](https://k90325248.github.io/shuo-ui/getting-started/theme/component-defaults) page adds `inputNumber.buttons`, `inputNumber.orientation`, `datepicker.displaySeparator`, `datepicker.weekStart` and `datepicker.showWeekday`; the [Locales and messages](https://k90325248.github.io/shuo-ui/getting-started/theme/messages) page adds `inputNumber.increment`, `inputNumber.decrement`, `datepicker.weekday` and `datepicker.weekdays`.

## 📦 Installation

```bash
pnpm add github:k90325248/shuo-ui#v3.1.0
pnpm add @iconify-json/lucide # recommended, icons are bundled
```

Enable the module in `nuxt.config.ts` and add `@import '@shuo/ui/css';` to your CSS; see [Installation](https://k90325248.github.io/shuo-ui/getting-started/overview/installation) on the docs site.
