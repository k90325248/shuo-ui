# v3.3.1

> Released on November 24, 2026

Fixes stuck Nuxt UI toasts: after certain interactions, the next toast showed no progress bar and never closed on its own. Upgrading from 3.3.0 needs no code changes.

## 🐛 Bug Fixes

- **New toasts had no progress bar and never closed:** a bug in reka-ui 2.11.0 (the latest release). If the last toast was closed while the pointer was over it (calling `toast.remove()`, clicking an action, swiping it away, or clicking X in browsers where buttons do not take focus on click), the toasts stayed paused and the next toast never started its timer. Shuo UI now has reka-ui resume the timer when a new toast appears and nothing should pause it (the window is focused and neither the pointer nor focus is on the toasts). Toasts still pause while hovered and while the window is unfocused.

## ✨ New option

- **shuoUi.toastPauseFix (default true):** turns the fix above on or off; set it to `false` to disable it. The fix and this option will be removed once reka-ui fixes the bug: [Module options](https://k90325248.github.io/shuo-ui/getting-started/theme/module-options)

## 📦 Installation

```bash
pnpm add github:k90325248/shuo-ui#v3.3.1
pnpm add @iconify-json/lucide # recommended, icons are bundled
```

Enable the module in `nuxt.config.ts` and add `@import '@shuo/ui/css';` to your CSS; see [Installation](https://k90325248.github.io/shuo-ui/getting-started/overview/installation) on the docs site.
