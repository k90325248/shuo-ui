# v1.3.0

> Released on October 29, 2026

The first-load skeleton of tables and list cards now has a configurable row count and height, also site-wide. Without these settings everything behaves as in 1.2.1; upgrading needs no code changes.

## ✨ Highlights

### 🦴 Configure the first-load skeleton rows and height

`ShuoTable` and `ShuoListCard` add `skeleton-rows` and `skeleton-class`: the first sets the skeleton row count (default `3`, at least 1 row), the second the height and other styles of each skeleton bar (default `h-6`, i.e. 24px, replaced as a whole when passed): [First-load skeleton in Table](https://k90325248.github.io/shuo-ui/components/layout/table#first-load-skeleton)

```vue
<ShuoListCard :data="rows" :columns="columns" :loading="loading" :skeleton-rows="5" skeleton-class="h-8" />
```

Both can be set site-wide with `components.table`, which also applies to the table inside `ShuoListCard`; values passed on the page win:

```ts
export default defineNuxtConfig({
  shuoUi: {
    components: {
      table: { skeletonRows: 5, skeletonClass: 'h-8' }
    }
  }
});
```

## 📖 Docs site

- The Table, ListCard and [Component defaults](https://k90325248.github.io/shuo-ui/getting-started/theme/component-defaults) pages describe the skeleton row count and height.

## 📦 Installation

```bash
pnpm add github:k90325248/shuo-ui#v1.3.0
pnpm add @iconify-json/lucide # recommended, icons are bundled
```

Enable the module in `nuxt.config.ts` and add `@import '@shuo/ui/css';` to your CSS; see [Installation](https://k90325248.github.io/shuo-ui/getting-started/overview/installation) on the docs site.
