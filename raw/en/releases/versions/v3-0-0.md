# v3.0.0

> Released on November 2, 2026

Existing attachments in the file input are now downloaded on click and can be removed by the user. `ShuoFile`'s `fileUrl` is removed; read the upgrade notes below before upgrading.

## ✨ Highlights

### ⬇️ Existing attachments download on click

`ShuoFile` adds `download`: it is called only when the download button is pressed for an existing attachment, so pages no longer need to fetch the file up front and put it in `v-model`. Auth headers, POST and the like are up to the page. Return a `Blob` to have the component save it under `file-name`, or nothing if the page handled the download itself (for example by opening a new tab). While downloading, the button shows a spinner and ignores repeated clicks, a failure shows a toast, and the passed `signal` is aborted on unmount: [Existing attachments in File](https://k90325248.github.io/shuo-ui/components/phone-file/file#existing-attachments)

```vue
<ShuoFile
  v-model="file"
  :file-name="attachment.name"
  :download="(signal) => $fetch < Blob > (attachment.url, { headers, responseType: 'blob', signal })"
/>
```

### ✖️ Existing attachments can be removed, and clearing empties the field

`ShuoFile` adds `clear`, following the same rules as the select menu and date picker: on by default, off by default inside a `required` `UFormField`, and configurable site-wide with `components.file.clear`. The clear button now also removes an existing attachment. Clearing sets `v-model` to `null` and `file-name` to `''`, leaving the field completely empty so a new file can be selected. Bind `v-model:file-name` so the page can tell from `''` that the user removed the existing attachment: [Clearing in File](https://k90325248.github.io/shuo-ui/components/phone-file/file#clearing)

```vue
<ShuoFile v-model="file" v-model:file-name="fileName" :download="download" :clear="canRemove" />
```

## ⚠️ Upgrade notes

### `fileUrl` is removed; use `download`

`ShuoFile` no longer accepts `file-url`, and passing it downloads nothing; an existing attachment without `download` only shows its name, with the select file button at the end. Search your project for `file-url` and `fileUrl` and pass a download function instead:

```vue
<!-- 2.x -->
<ShuoFile v-model="file" :file-name="name" :file-url="url" />
<!-- 3.0.0 -->
<ShuoFile
  v-model="file"
  :file-name="name"
  :download="(signal) => $fetch < Blob > (url, { responseType: 'blob', signal })"
/>
```

Pages that pre-fetched the attachment to send auth headers and put it in `v-model` as a `File` can keep `v-model` at `null` and show the existing attachment with `file-name` and `download`.

### When the clear button is shown

- **Existing attachments show a clear button:** previously only a local `File` could be cleared. After upgrading, an existing attachment with only `file-name` shows a clear button too; pass `:clear="false"` where removal is not allowed.
- **Hidden by default in required fields:** inside a `required` `UFormField`, a local `File` no longer shows a clear button either; users can still select another file to replace it. Pass `clear` explicitly when you want it.
- **Clearing also empties the file name:** previously, clearing a local `File` went back to showing `file-name`; now `file-name` is cleared to `''` as well.

## 📖 Docs site

- **2.x docs:** once 3.0.0 is deployed, the site root shows the 3.x docs and the 2.x docs move to `v2/`; switch between them with the version menu in the header.
- The File page rewrites the [Existing attachments](https://k90325248.github.io/shuo-ui/components/phone-file/file#existing-attachments) section and adds a [Clearing](https://k90325248.github.io/shuo-ui/components/phone-file/file#clearing) section; the [Component defaults](https://k90325248.github.io/shuo-ui/getting-started/theme/component-defaults) page adds `file.clear`.

## 📦 Installation

```bash
pnpm add github:k90325248/shuo-ui#v3.0.0
pnpm add @iconify-json/lucide # recommended, icons are bundled
```

Enable the module in `nuxt.config.ts` and add `@import '@shuo/ui/css';` to your CSS; see [Installation](https://k90325248.github.io/shuo-ui/getting-started/overview/installation) on the docs site.
