# v3.2.0

> Released on November 5, 2026

The number input now centers the number between horizontal step buttons by default; the date picker puts `aria-label` and `aria-labelledby` on the input when it is not wrapped in `UFormField`. Number inputs without step buttons work as in 3.1.0.

## ✨ Highlights

### ➕ Number input: centered between horizontal buttons

When `ShuoInputNumber` has `buttons` in horizontal layout (`orientation="horizontal"`, the default), the built-in `ui.base` is now `text-center`, so the number sits between the decrement and increment buttons. Vertical layout (both buttons stacked on the right) and fields without buttons stay `text-right`. `ui.base` still overrides it; pass `text-right` or `text-left` to align it right or left: [Centered numbers in InputNumber](https://k90325248.github.io/shuo-ui/components/text/input-number#centered-numbers)

```vue
<!-- Centered by default -->
<ShuoInputNumber v-model="hours" buttons :step="0.25" :decimal="2" unit="hr" />
<!-- Keep the 3.1.0 right alignment -->
<ShuoInputNumber v-model="hours" buttons :ui="{ base: 'text-right' }" />
```

## ⚠️ Upgrade notes

### Numbers between horizontal step buttons are centered

Fields that use `buttons` (horizontal layout) since 3.1.0 change from right-aligned to centered after upgrading. Pass `:ui="{ base: 'text-right' }"` to keep them right-aligned. When `ui.base` uses the function form, horizontal buttons now pass `text-center` as the default (no longer `text-right`), so for example `defaults.replace('text-right', 'text-left')` has no effect there; pass the alignment class you want directly instead. Vertical layout and fields without buttons are unchanged.

## 🐛 Bug Fixes

- **ShuoDatepicker had no accessible name outside UFormField:** The component put every HTML attribute on its outer container, so `aria-label` and `aria-labelledby` never reached the native input, and fields not wrapped in `UFormField` (such as inline date fields in tables or filter bars) had no accessible name. Both attributes now go on the input and are kept when a `mode`, `roc` or `range` change rebuilds it; other attributes stay on the outer container. Fields inside `UFormField` still take their name from the label.

## 📖 Docs site

- The InputNumber page's [Step buttons](https://k90325248.github.io/shuo-ui/components/text/input-number#step-buttons), [Centered numbers](https://k90325248.github.io/shuo-ui/components/text/input-number#centered-numbers) and styling table cover the centered default with horizontal buttons and how to override it.
- The Datepicker page's [Styling](https://k90325248.github.io/shuo-ui/components/date/datepicker#styling) notes that `aria-label` and `aria-labelledby` go on the input.

## 📦 Installation

```bash
pnpm add github:k90325248/shuo-ui#v3.2.0
pnpm add @iconify-json/lucide # recommended, icons are bundled
```

Enable the module in `nuxt.config.ts` and add `@import '@shuo/ui/css';` to your CSS; see [Installation](https://k90325248.github.io/shuo-ui/getting-started/overview/installation) on the docs site.
