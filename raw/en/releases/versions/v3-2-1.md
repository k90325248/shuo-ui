# v3.2.1

> Released on November 12, 2026

Fixes `ShuoDatepicker` ignoring date clicks inside a modal `UModal` or `USlideover`. Upgrading from 3.2.0 needs no code changes.

## 🐛 Bug Fixes

- **ShuoDatepicker ignored date clicks inside Modal and Slideover:** a modal Reka Dialog sets `pointer-events: none` on `body`, and the calendar menu, teleported to `body`, inherited it, so clicks fell through to the dialog behind it and never reached `v-model`. The menu now sets `pointer-events: auto`; single and range picking both update the value, and the dialog stays open after the calendar closes.
- **Keyboard focus was pulled back and Esc closed the dialog too:** the menu sat outside the dialog's focus trap, so after opening the calendar with Enter focus went back to the dialog and the arrow keys could not move between dates; Esc with the calendar open also closed the dialog. Focus moves inside the menu and Esc no longer reach the dialog, so Esc closes only the calendar and returns focus to the input, and Esc on other elements in the dialog still closes it.

Projects that worked around this with a global `.form-datepicker-menu { pointer-events: auto; }` rule, or by checking for an open calendar in the `UModal` `content.onEscapeKeyDown`, can remove the workaround after upgrading.

## 📦 Installation

```bash
pnpm add github:k90325248/shuo-ui#v3.2.1
pnpm add @iconify-json/lucide # recommended, icons are bundled
```

Enable the module in `nuxt.config.ts` and add `@import '@shuo/ui/css';` to your CSS; see [Installation](https://k90325248.github.io/shuo-ui/getting-started/overview/installation) on the docs site.
