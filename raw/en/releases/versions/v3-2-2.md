# v3.2.2

> Released on November 17, 2026

Raises the minimum `@nuxt/ui` version to `4.12.2` to patch a critical security vulnerability, and fixes the full-text tooltip closing right away when keyboard focus moves between options in a group. Upgrading from 3.2.1 needs no code changes, but your project's `@nuxt/ui` must be upgraded to `4.12.2` or later as well.

## 🔒 Security

- **Minimum @nuxt/ui is now ^4.12.2 (GHSA-x9jw-j844-v24h, CVSS 9.8):** before 4.12.2, Nuxt UI components passed `as` straight to reka-ui's `Primitive`, so an object carrying a `template` was compiled and run by Vue's CJS server renderer during SSR. Projects that render untrusted markdown through Comark or MDC (`@nuxt/content`), or let untrusted data reach `app.config.ui` or `<UTheme :props>`, could have arbitrary commands run on the server. Shuo UI components do not use `as`, `resolveAs` or `UTheme` themselves, but they share your project's `@nuxt/ui`, so the peer dependency minimum is raised and installing will prompt you to upgrade.

To upgrade:

```bash
pnpm add @nuxt/ui@^4.12.2
```

## 🐛 Bug Fixes

- **Full-text tooltip closed right away when moving focus between options:** when Tab in `ShuoCheckboxGroup` or the arrow keys in `ShuoRadioGroup` moved to another truncated option, the tooltip closed and reopened, and the old tooltip, not yet unmounted, received Reka's open event and closed the new one with it. The tooltip now stays open while focus is inside the group and updates to the current option's text and position; it still closes when focus leaves the group.

## 📦 Installation

```bash
pnpm add github:k90325248/shuo-ui#v3.2.2
pnpm add @iconify-json/lucide # recommended, icons are bundled
```

Enable the module in `nuxt.config.ts` and add `@import '@shuo/ui/css';` to your CSS; see [Installation](https://k90325248.github.io/shuo-ui/getting-started/overview/installation) on the docs site.
