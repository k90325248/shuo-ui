# v3.3.0

> Released on November 19, 2026

The date picker adds time-only modes for hours and minutes, with or without seconds. This release only adds features; upgrading from 3.2.2 needs no code changes.

## ✨ Highlights

### 🕒 Date picker: time only

`ShuoDatepicker` adds `mode="time"` (hours and minutes) and `mode="time-second"` (with seconds). The menu opens straight to the time panel with no calendar, and the bound value is a 24-hour `HH:mm` / `HH:mm:ss` string. The menu stays open while adjusting; clicking outside or pressing Esc keeps the current value. With `range` it binds `[start, end]`, and the start time cannot be later than the end time: [Datepicker modes](https://k90325248.github.io/shuo-ui/components/date/datepicker#modes)

```vue
<ShuoDatepicker v-model="time" mode="time" />
<!-- '14:02' -->
<ShuoDatepicker v-model="time" mode="time-second" />
<!-- '14:02:09' -->
<ShuoDatepicker v-model="hours" mode="time" range />
<!-- ['09:00', '18:00'] -->
```

- In the time-only modes the trailing icon is a clock, set with the new `time-icon` (`i-lucide-clock` by default) or site-wide with `components.datepicker.timeIcon`.
- `roc`, `separator`, `display-separator`, `min-date`, `max-date`, `year-range`, `week-start` and `show-weekday` have no effect in these modes.
- A bound value that does not match the format (such as `24:00`, or `08:05` for `time-second`) is cleared with a warning, as in the other modes.
- `formatDateDisplay` and `parseDateValue` also accept `time` and `time-second`: [Date formatting](https://k90325248.github.io/shuo-ui/utils/format/date)

## 📖 Docs site

- The Datepicker page's [Modes](https://k90325248.github.io/shuo-ui/components/date/datepicker#modes) section and example include `time` and `time-second`, and [Icons and clear button](https://k90325248.github.io/shuo-ui/components/date/datepicker#icons-and-clear-button) covers `time-icon`.
- `timeIcon` is added to `datepicker` in [Component defaults](https://k90325248.github.io/shuo-ui/getting-started/theme/component-defaults#configurable-props).

## 📦 Installation

```bash
pnpm add github:k90325248/shuo-ui#v3.3.0
pnpm add @iconify-json/lucide # recommended, icons are bundled
```

Enable the module in `nuxt.config.ts` and add `@import '@shuo/ui/css';` to your CSS; see [Installation](https://k90325248.github.io/shuo-ui/getting-started/overview/installation) on the docs site.
