# v1.2.1

> 發佈於 2026年10月27日

文件網站新增「Agents」分組，讓 Cursor、Claude Code 等 AI 工具也能正確使用 Shuo UI：提供 LLMs.txt，以及可直接安裝的 Shuo UI skill。元件沒有任何變更，從 1.2.0 升級不需要修改程式碼。

## ✨ Highlights

### 🤖 給 AI 工具的 Skill

新的 `shuo-ui` skill 教 AI coding agent 用 Shuo UI 撰寫表單與查詢頁面：各元件的 v-model 型別與空值約定、搭配 `UForm` 與 Valibot 的驗證規則、查詢卡片搭配清單卡片的分頁寫法、`shuoUi` 全站設定等。安裝後在 agent 的對話框輸入 `/shuo-ui` 即可呼叫：[Skills](https://k90325248.github.io/shuo-ui/getting-started/agents/skills)

```bash
npx skills add k90325248/shuo-ui
```

- Cursor 可在文件頁按「安裝 Skill」一鍵安裝，Claude Code 使用 `claude skill add`，其他工具可直接引用 GitHub 上的 `skills/shuo-ui/SKILL.md`。
- skill 檔案放在公開 repo 的 `skills/shuo-ui`，也發佈在文件網站的 `/.well-known/skills/`；套件本身不包含這些檔案，安裝的內容與 1.2.0 相同。

### 📄 LLMs.txt

文件網站提供 [`/llms.txt`](https://k90325248.github.io/shuo-ui/llms.txt)（所有頁面的索引）與 [`/llms-full.txt`](https://k90325248.github.io/shuo-ui/llms-full.txt)（完整文件），每個頁面也可在網址後加上 `.md` 取得 markdown 版本。在 ChatGPT、Claude 等工具中提供這些網址，AI 就能依照文件回答：[LLMs.txt](https://k90325248.github.io/shuo-ui/getting-started/agents/llms-txt)

## 📖 文件網站

- **新頁面：** 「開始使用」新增 Agents 分組，包含 [LLMs.txt](https://k90325248.github.io/shuo-ui/getting-started/agents/llms-txt) 與 [Skills](https://k90325248.github.io/shuo-ui/getting-started/agents/skills)。

## 📦 安裝

```bash
pnpm add github:k90325248/shuo-ui#v1.2.1
pnpm add @iconify-json/lucide # 建議，圖示會直接打包
```

在 `nuxt.config.ts` 啟用模組，並在 CSS 加上 `@import '@shuo/ui/css';`，步驟見文件網站的[安裝](https://k90325248.github.io/shuo-ui/getting-started/overview/installation)。
