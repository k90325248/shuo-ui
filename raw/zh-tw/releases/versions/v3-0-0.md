# v3.0.0

> 發佈於 2026年11月2日

檔案選擇的既有附件改為點擊才下載，並可由使用者移除。`ShuoFile` 的 `fileUrl` 已移除，升級前請先看下方的升級須知。

## ✨ Highlights

### ⬇️ 既有附件點擊才下載

`ShuoFile` 新增 `download`：既有附件按下載按鈕時才呼叫，頁面不必事先把檔案抓下來放進 `v-model`。驗證標頭、POST 等請求方式都由頁面決定；回傳 `Blob` 由元件以 `file-name` 儲存，不回傳則視為頁面已自行處理（例如開新分頁）。下載中按鈕顯示轉圈並防止重複點擊，失敗時顯示 Toast，元件卸載時會中止傳入的 `signal`：[File 的既有附件](https://k90325248.github.io/shuo-ui/components/phone-file/file#%E6%97%A2%E6%9C%89%E9%99%84%E4%BB%B6)

```vue
<ShuoFile
  v-model="file"
  :file-name="attachment.name"
  :download="(signal) => $fetch < Blob > (attachment.url, { headers, responseType: 'blob', signal })"
/>
```

### ✖️ 既有附件可以移除，清除後完全清空

`ShuoFile` 新增 `clear`，規則與下拉選單、日期選擇器相同：預設開啟，包在 `required` 的 `UFormField` 內時預設關閉，也可以在全站設定 `components.file.clear`。清除按鈕現在也會移除既有附件，清除後 `v-model` 為 `null`、`file-name` 為 `''`，欄位完全清空，可重新選檔。以 `v-model:file-name` 綁定，頁面就能從 `''` 得知使用者移除了既有附件：[File 的清除](https://k90325248.github.io/shuo-ui/components/phone-file/file#%E6%B8%85%E9%99%A4)

```vue
<ShuoFile v-model="file" v-model:file-name="fileName" :download="download" :clear="canRemove" />
```

## ⚠️ 升級須知

### `fileUrl` 已移除，改用 `download`

`ShuoFile` 不再接受 `file-url`，傳了也不會下載；沒有傳 `download` 的既有附件只顯示檔名，尾端是選擇檔案按鈕。請全專案搜尋 `file-url`、`fileUrl`，改為傳入下載函式：

```vue
<!-- 2.x -->
<ShuoFile v-model="file" :file-name="name" :file-url="url" />
<!-- 3.0.0 -->
<ShuoFile
  v-model="file"
  :file-name="name"
  :download="(signal) => $fetch < Blob > (url, { responseType: 'blob', signal })"
/>
```

先前為了帶驗證標頭而預先下載、把附件包成 `File` 放進 `v-model` 的頁面，改為 `v-model` 維持 `null`，以 `file-name` 與 `download` 顯示既有附件。

### 清除按鈕的顯示規則改變

- **既有附件會顯示清除按鈕：** 先前只有本機 `File` 才能清除。升級後只傳 `file-name` 的既有附件也會顯示清除按鈕，不允許移除的地方請傳 `:clear="false"`。
- **必填欄位預設不顯示：** 包在 `required` 的 `UFormField` 內時，本機 `File` 也不再顯示清除按鈕，使用者仍可重新選檔替換；需要時明確傳 `clear`。
- **清除後連同檔名清空：** 先前清除本機 `File` 後會改回顯示 `file-name`，現在 `file-name` 也一併清為 `''`。

## 📖 文件網站

- **2.x 文件：** 3.0.0 部署後，網站根目錄改為 3.x 文件，2.x 文件移到 `v2/`，可從標題列的版本選單切換。
- File 頁改寫[既有附件](https://k90325248.github.io/shuo-ui/components/phone-file/file#%E6%97%A2%E6%9C%89%E9%99%84%E4%BB%B6)一節並新增[清除](https://k90325248.github.io/shuo-ui/components/phone-file/file#%E6%B8%85%E9%99%A4)一節；[全站元件預設值](https://k90325248.github.io/shuo-ui/getting-started/theme/component-defaults)頁新增 `file.clear`。

## 📦 安裝

```bash
pnpm add github:k90325248/shuo-ui#v3.0.0
pnpm add @iconify-json/lucide # 建議，圖示會直接打包
```

在 `nuxt.config.ts` 啟用模組，並在 CSS 加上 `@import '@shuo/ui/css';`，步驟見文件網站的[安裝](https://k90325248.github.io/shuo-ui/getting-started/overview/installation)。
