# v3.1.0

> 發佈於 2026年11月5日

數字輸入新增增減按鈕與步進；日期選擇器可以設定每週的起始日、在輸入框顯示星期，顯示的分隔符號也能和綁定值分開設定；單選群組新增卡片外觀。沒有使用新參數時與 3.0.0 相同，升級不需要修改程式碼。

## ✨ Highlights

### ➕ 數字輸入：增減按鈕與步進

`ShuoInputNumber` 新增 `buttons`（預設關閉）、`step`（預設 `1`）、`min`、`max` 與 `orientation`（`horizontal` 左減右加、`vertical` 上下疊放在右側）。方向鍵增減一步、PageUp／PageDown 增減 10 步、Home／End 跳到 `min`／`max`，按住按鈕可連續增減；以十進位計算，`0.25` 連加不會出現浮點誤差。空值按增加或減少都從 `min`（沒有則 `0`）開始，每次增減都會觸發表單驗證：[InputNumber 的增減按鈕與步進](https://k90325248.github.io/shuo-ui/components/text/input-number#%E5%A2%9E%E6%B8%9B%E6%8C%89%E9%88%95%E8%88%87%E6%AD%A5%E9%80%B2)

```vue
<ShuoInputNumber v-model="hours" buttons :step="0.25" :min="0.25" :max="24" :decimal="2" unit="小時" />
```

`min`、`max` 只限制按鈕與鍵盤，手動輸入超出範圍時不會自動修正，範圍驗證仍寫在 schema。整個專案都要顯示按鈕時，設定全站預設值 `components.inputNumber.buttons: true`。沒有設定 `buttons`、`step`、`min`、`max` 時，方向鍵與畫面都和 3.0.0 相同。

### 📅 日期選擇器：設定週起始日

`ShuoDatepicker` 新增 `week-start`（`0` 為週日、`1` 為週一，依此類推，預設 `0`）。星期標題列與六週排列都從這天開始，範圍與 `min-date`、`max-date` 的行為不變。值可以隨時改變，已掛載的元件下次開啟日曆即套用，適合讓使用者在設定頁切換「星期一／星期日」：[Datepicker 的週起始日與顯示星期](https://k90325248.github.io/shuo-ui/components/date/datepicker#%E9%80%B1%E8%B5%B7%E5%A7%8B%E6%97%A5%E8%88%87%E9%A1%AF%E7%A4%BA%E6%98%9F%E6%9C%9F)

```vue
<ShuoDatepicker v-model="date" :week-start="settings.weekStart" />
```

也可以在全站設定，明確傳入的 prop 優先：

```ts
export default defineNuxtConfig({
  shuoUi: {
    components: {
      datepicker: { weekStart: 1 }
    }
  }
});
```

### 🗓️ 日期選擇器：輸入框顯示星期

新增 `show-weekday`，在日期後加上星期，例如「2026/11/05（星期四）」，英文為「2026/11/05 (Thu)」；只影響顯示，`v-model` 不變。套用於 `date`、`datetime`、`datetime-second`（時間接在星期之後），`year`、`month` 忽略，範圍兩端各自顯示。格式與星期名稱可用 `messages.datepicker.weekday`、`weekdays` 覆寫，也可在全站設定 `components.datepicker.showWeekday`。

```vue
<ShuoDatepicker v-model="date" show-weekday :roc="false" separator="-" display-separator="-" />
```

### ➖ 日期選擇器：顯示用的分隔符號

新增 `display-separator`，設定輸入框顯示日期時的分隔符號（預設 `/`）。`separator` 仍只決定綁定值的格式，兩者分開設定：上例綁定 `2026-11-05`，顯示「2026-11-05（星期四）」；沒有設定 `display-separator` 時與 3.0.0 相同，仍顯示斜線。年與年月模式依文案格式顯示，不受影響。西元專案可在全站設定一次：

```ts
export default defineNuxtConfig({
  shuoUi: {
    components: {
      datepicker: { roc: false, separator: '-', displaySeparator: '-' }
    }
  }
});
```

### 🃏 單選群組：卡片外觀

`ShuoRadioGroup` 新增 `variant`（`list`、`card`）與 `indicator`（`start`、`end`、`hidden`），可搭配所有 `orientation`（含 `grid`、`auto`）、`label-key`／`value-key`／`description-key` 與 `#item-append` 使用。水平卡片在空間不足時縮小，長文字截斷並以 Tooltip 顯示完整文字；垂直與 `grid` 的卡片填滿寬度。表單錯誤、停用與鍵盤聚焦都有對應的卡片樣式。另外新增 `#label`、`#description` slot，可在卡片內放自訂內容：[RadioGroup 的卡片外觀](https://k90325248.github.io/shuo-ui/components/choice/radio-group#%E5%8D%A1%E7%89%87%E5%A4%96%E8%A7%80)

```vue
<ShuoRadioGroup
  v-model="theme"
  :items="themes"
  variant="card"
  orientation="grid"
  indicator="hidden"
  :ui="{ fieldset: 'grid-cols-3', item: 'min-w-0', wrapper: 'w-full', description: 'w-full' }"
>
  <template #description="{ item }">
    <ThemePreview :theme="item.value" />
  </template>
</ShuoRadioGroup>
```

核取方塊與複選群組仍不支援 `variant`、`indicator`；單選群組不支援 Nuxt UI 的 `table` 與 `highlight`。

## 📦 安裝

```bash
pnpm add github:k90325248/shuo-ui#v3.1.0
pnpm add @iconify-json/lucide # 建議，圖示會直接打包
```

在 `nuxt.config.ts` 啟用模組，並在 CSS 加上 `@import '@shuo/ui/css';`，步驟見文件網站的[安裝](https://k90325248.github.io/shuo-ui/getting-started/overview/installation)。
