# v3.2.0

> 發佈於 2026年11月5日

數字輸入開啟水平排列的增減按鈕時，數字改為預設置中；日期選擇器未包 `UFormField` 時，`aria-label`、`aria-labelledby` 改為套用到輸入框。沒有使用增減按鈕的數字輸入與 3.1.0 相同。

## ✨ Highlights

### ➕ 數字輸入：水平按鈕時數字置中

`ShuoInputNumber` 開啟 `buttons` 且為水平排列（`orientation="horizontal"`，預設）時，`ui.base` 內建改為 `text-center`，數字位於減少與增加按鈕中間。垂直排列（兩個按鈕疊在右側）與沒有按鈕時維持 `text-right`。`ui.base` 仍可覆寫，傳入 `text-right`、`text-left` 即可改回靠右或靠左：[InputNumber 的數字置中](https://k90325248.github.io/shuo-ui/components/text/input-number#%E6%95%B8%E5%AD%97%E7%BD%AE%E4%B8%AD)

```vue
<!-- 預設置中 -->
<ShuoInputNumber v-model="hours" buttons :step="0.25" :decimal="2" unit="小時" />
<!-- 維持 3.1.0 的靠右 -->
<ShuoInputNumber v-model="hours" buttons :ui="{ base: 'text-right' }" />
```

## ⚠️ 升級須知

### 水平增減按鈕的數字對齊改為置中

3.1.0 起使用 `buttons`（水平排列）的欄位，升級後數字會從靠右改為置中。要維持靠右時傳入 `:ui="{ base: 'text-right' }"`。以函式寫法覆寫 `ui.base` 的欄位，水平按鈕時收到的預設值是 `text-center`（不再含 `text-right`），例如 `defaults.replace('text-right', 'text-left')` 在這種情況下不會生效，請改為直接傳入要的對齊 class。垂直排列與沒有按鈕的欄位不受影響。

## 🐛 Bug Fixes

- **ShuoDatepicker 未包 UFormField 時螢幕閱讀器念不出欄位名稱：** 先前元件把所有 HTML attributes 都放在外層容器，傳入的 `aria-label`、`aria-labelledby` 沒有到達原生輸入框，未包 `UFormField` 的欄位（例如表格內或篩選列的 inline 日期欄）沒有無障礙名稱。現在這兩個屬性改為套用到輸入框，切換 `mode`、`roc`、`range` 重建輸入框後也會保留；其餘 attributes 仍在外層容器。包在 `UFormField` 內的欄位照舊由標籤提供名稱。

```bash

```
