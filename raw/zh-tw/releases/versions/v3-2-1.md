# v3.2.1

> 發佈於 2026年11月12日

修正 `ShuoDatepicker` 放在 modal 模式的 `UModal`、`USlideover` 內時，點選日期沒有反應的問題。從 3.2.0 升級不需要修改程式碼。

## 🐛 Bug Fixes

- **ShuoDatepicker 在 Modal、Slideover 內點選日期沒有反應：** Reka Dialog 以 modal 模式開啟時會把 `body` 設為 `pointer-events: none`，日曆選單 teleport 至 `body` 後一併繼承，點擊穿透到後方對話框內的元素，值不會寫入 `v-model`。選單改為明確使用 `pointer-events: auto`，單日與範圍選取都能正常寫入，日曆關閉後對話框仍開著。
- **Modal 內鍵盤操作日曆時焦點被拉回、Esc 連同對話框一起關閉：** 選單不在對話框的焦點陷阱內，以 Enter 開啟日曆後焦點會被拉回對話框，方向鍵無法移動日期；日曆開啟時按 Esc 也會同時關閉對話框。現在選單內的焦點移動與 Esc 不再傳到外層對話框，Esc 只關閉日曆並把焦點還給輸入框，之後在對話框其他元素上按 Esc 照常關閉對話框。

先前以全域 CSS `.form-datepicker-menu { pointer-events: auto; }`，或在 `UModal` 的 `content.onEscapeKeyDown` 檢查日曆是否開啟來繞過的專案，升級後可以拿掉。

## 📦 安裝

```bash
pnpm add github:k90325248/shuo-ui#v3.2.1
pnpm add @iconify-json/lucide # 建議，圖示會直接打包
```

在 `nuxt.config.ts` 啟用模組，並在 CSS 加上 `@import '@shuo/ui/css';`，步驟見文件網站的[安裝](https://k90325248.github.io/shuo-ui/getting-started/overview/installation)。
