# v3.3.0

> 發佈於 2026年11月19日

日期選擇器新增只選時間的模式，可選時分或時分秒。這一版只新增功能，從 3.2.2 升級不需要修改程式碼。

## ✨ Highlights

### 🕒 日期選擇器：只選時間

`ShuoDatepicker` 新增 `mode="time"`（時分）與 `mode="time-second"`（時分秒）。開啟後直接顯示時間面板、不顯示日曆，綁定值為 24 小時制的 `HH:mm`／`HH:mm:ss` 字串，調整時選單不會自動關閉，點外部或按 Esc 即保留目前的值。搭配 `range` 時綁定 `[起, 迄]`，起時不能晚於迄時：[Datepicker 的選擇模式](https://k90325248.github.io/shuo-ui/components/date/datepicker#%E9%81%B8%E6%93%87%E6%A8%A1%E5%BC%8F)

```vue
<ShuoDatepicker v-model="time" mode="time" />
<!-- '14:02' -->
<ShuoDatepicker v-model="time" mode="time-second" />
<!-- '14:02:09' -->
<ShuoDatepicker v-model="hours" mode="time" range />
<!-- ['09:00', '18:00'] -->
```

- 只選時間時尾端改為時鐘圖示，新的 `time-icon` 可更換（預設 `i-lucide-clock`），也能以全站預設值 `components.datepicker.timeIcon` 設定。
- `roc`、`separator`、`display-separator`、`min-date`、`max-date`、`year-range`、`week-start`、`show-weekday` 在這兩種模式不生效。
- 不符合格式的綁定值（例如 `24:00`，或 `time-second` 收到 `08:05`）與其他模式一樣清空並警告。
- `formatDateDisplay`、`parseDateValue` 也接受 `time`、`time-second`：[日期格式化](https://k90325248.github.io/shuo-ui/utils/format/date)

## 📦 安裝

```bash
pnpm add github:k90325248/shuo-ui#v3.3.0
pnpm add @iconify-json/lucide # 建議，圖示會直接打包
```

在 `nuxt.config.ts` 啟用模組，並在 CSS 加上 `@import '@shuo/ui/css';`，步驟見文件網站的[安裝](https://k90325248.github.io/shuo-ui/getting-started/overview/installation)。
