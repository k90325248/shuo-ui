# v2.0.0

> Released on November 2, 2026

The clear button of select menus and date pickers is now `clear` on both, and on by default. The date picker's `clearable` is renamed; read the upgrade notes below before upgrading.

## ✨ Highlights

### ✖️ One `clear` prop for the clear button, on by default

`ShuoSelectMenu` adds `clear` and `clear-icon`: once a value is selected, a clear button replaces the trailing arrow, and clearing sets the value to `empty-value` (`[]` for multiple). It is hidden while disabled or loading: [Clear button in SelectMenu](https://k90325248.github.io/shuo-ui/v2/components/choice/select-menu#clear-button)

`ShuoDatepicker` renames `clearable` to `clear`, matching the select menu: [Icons and clear button in Datepicker](https://k90325248.github.io/shuo-ui/v2/components/date/datepicker#icons-and-clear-button)

Both are on by default; pass `:clear="false"` where you don't want it:

```vue
<ShuoSelectMenu v-model="state.type" :items="items" :clear="false" />
<ShuoDatepicker v-model="state.date" :clear="false" />
```

Inside a `required` `UFormField` it is off by default, so a required field cannot be emptied with one click; pass `clear` explicitly when you still want it:

```vue
<UFormField label="Type" name="type" required>
  <ShuoSelectMenu v-model="state.type" :items="items" />
</UFormField>
```

Each can also be set site-wide. The order is: `clear` passed explicitly > `required` on `UFormField` > site-wide setting > built-in default (on):

```ts
export default defineNuxtConfig({
  shuoUi: {
    components: {
      selectMenu: { clear: false },
      datepicker: { clear: true }
    }
  }
});
```

## ⚠️ Upgrade notes

### `clearable` is renamed to `clear`

`ShuoDatepicker`'s `clearable` and the site-wide `components.datepicker.clearable` are now `clear`. The old name no longer works: `clearable` on the component is ignored as a plain attribute, and the site-wide setting is skipped with a warning at startup. Search your project for `clearable` and change it to `clear`; where you wrote `clearable` to turn the button on, you can simply remove it outside required fields (see the next section), since the button is now shown by default.

### The clear button is shown by default

Previously the select menu had no clear button and the date picker hid it by default. After upgrading, both show a clear button when they have a value (except inside a `required` `UFormField`), and a selected select menu shows it in place of the trailing arrow. To keep the previous behavior, turn it off site-wide:

```ts
export default defineNuxtConfig({
  shuoUi: {
    components: {
      selectMenu: { clear: false },
      datepicker: { clear: false }
    }
  }
});
```

A date picker in a required field that had `clearable` needs `clear` after the rename to keep its clear button; simply removing it hides the button because the field is required. Fields that are only required in the schema, without `required` on `UFormField`, still show the clear button; add `required` to the `UFormField` or pass `:clear="false"` to hide it.

On very narrow fields (about 90px or less) the clear button can leave no room for the text; pass `:clear="false"` on those.

## 📖 Docs site

- **1.x docs:** once 2.0.0 is deployed, the site root shows the 2.x docs and the 1.x docs move to `v1/`; switch between them with the version menu in the header.
- The SelectMenu page adds a [Clear button](https://k90325248.github.io/shuo-ui/v2/components/choice/select-menu#clear-button) section; the Datepicker and [Component defaults](https://k90325248.github.io/shuo-ui/v2/getting-started/theme/component-defaults) pages use `clear`.

## 📦 Installation

```bash
pnpm add github:k90325248/shuo-ui#v2.0.0
pnpm add @iconify-json/lucide # recommended, icons are bundled
```

Enable the module in `nuxt.config.ts` and add `@import '@shuo/ui/css';` to your CSS; see [Installation](https://k90325248.github.io/shuo-ui/v2/getting-started/overview/installation) on the docs site.
