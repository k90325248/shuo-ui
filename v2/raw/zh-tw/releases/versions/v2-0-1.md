# v2.0.1

> 發佈於 2026年11月2日

修正 `ShuoTable` 放在彈窗等有縮放動畫的容器內時，表格底部被裁掉的問題。從 2.0.0 升級不需要修改程式碼。

## 🐛 Bug Fixes

- **ShuoTable 在彈窗內底部被裁掉：** 表格在 `UModal` 開啟的縮放動畫（0.95 → 1）期間掛載時，資料區量到縮小後的高度，動畫結束後也不會修正，捲到最底時最後一筆只露出上半部。改為量測不受 CSS transform 影響的排版高度，`Popover` 或自訂縮放動畫內的表格同樣適用。先前以 `:transition="false"` 繞過的頁面，升級後可以拿掉。

## 📦 安裝

```bash
pnpm add github:k90325248/shuo-ui#v2.0.1
pnpm add @iconify-json/lucide # 建議，圖示會直接打包
```

在 `nuxt.config.ts` 啟用模組，並在 CSS 加上 `@import '@shuo/ui/css';`，步驟見文件網站的[安裝](https://k90325248.github.io/shuo-ui/v2/getting-started/overview/installation)。
