選擇

Checkbox

UCheckbox
單一核取方塊，可自訂勾選值，文字旁可放附加內容。

v-model: string | number | boolean，必須提供。

用法

勾選值

true-value 是勾選時的綁定值，預設數字 1；false-value 是取消時的綁定值，預設數字 0。後端使用 Y／N 或布林值時改成對應的值；整個專案統一時可在全站設定 trueValue、falseValue 的預設值，見可設定的項目。

<template>
  <ExampleOptions>
    <ExampleOption
      v-model="trueValue"
      label="true-value"
      :items="[1, 'Y', true]"
    />
    <ExampleOption
      v-model="falseValue"
      label="false-value"
      :items="[0, 'N', false]"
    />
  </ExampleOptions>
  <ShuoCheckbox
    v-model="active"
    :true-value="trueValue"
    :false-value="falseValue"
  />
</template>

<script setup lang="ts">
type Value = string | number | boolean;

// 預設勾選為 1、取消為 0；後端用 Y／N 或布林值時改用對應的值。
const trueValue = ref<Value>(1);
const falseValue = ref<Value>(0);
const active = ref<Value>(1);
</script>
  • 綁定值不等於 true-value 時顯示未勾選；範例中只改 true-value 時，原本的值不再相符，會顯示為未勾選。
  • 原生表單送出時帶出 true-value，而不是瀏覽器預設的 on。

顯示文字

label 預設為「啟用」（英文為「Enable」），依語系切換，可由文案 checkbox.label 覆寫，見多語系與文案。

<template>
  <ExampleOptions>
    <ExampleOption v-model="label" label="label" :items="labels" />
  </ExampleOptions>
  <!-- 容器較窄，文字過長時截斷，滑過或聚焦時以 Tooltip 顯示完整文字 -->
  <div class="w-56 max-w-full">
    <ShuoCheckbox v-model="agree" :label="label" />
  </div>
</template>

<script setup lang="ts">
const labels = [
  '啟用',
  '我已閱讀並同意',
  '我已閱讀並同意個人資料蒐集、處理及利用告知事項'
];
const label = ref(labels[2]!);
const agree = ref<string | number | boolean>(0);
</script>

文字單行顯示，超過容器寬度時截斷，滑過或聚焦時以 Tooltip 顯示完整文字，觸控裝置長按顯示（見 Tooltip）；長按顯示提示時不會改變勾選。

說明文字

description 顯示在文字下方。沒有說明時外框高度對齊同尺寸的輸入框；有說明時往下撐高，說明文字換行，第一行文字仍與旁邊沒有說明的欄位對齊。

每週寄送一次最新公告與活動資訊，可以隨時取消訂閱

<template>
  <div class="grid gap-4 sm:grid-cols-2">
    <UFormField label="帳號">
      <ShuoInputText v-model="account" />
    </UFormField>

    <!-- 有說明時撐高，說明換行；第一行與旁邊的輸入框對齊 -->
    <UFormField label="通知">
      <ShuoCheckbox
        v-model="subscribe"
        label="訂閱電子報"
        description="每週寄送一次最新公告與活動資訊，可以隨時取消訂閱"
      />
    </UFormField>
  </div>
</template>

<script setup lang="ts">
const account = ref('wang');
const subscribe = ref(1);
</script>

顏色與圖示

沿用 UCheckbox 的 color 與 icon（勾選時的圖示）。

<template>
  <ExampleOptions>
    <ExampleOption v-model="color" label="color" :items="colors" />
    <ExampleOption
      v-model="icon"
      label="icon"
      :items="['i-lucide-check', 'i-lucide-x', 'i-lucide-heart']"
    />
  </ExampleOptions>
  <ShuoCheckbox v-model="agree" label="訂閱電子報" :color :icon />
</template>

<script setup lang="ts">
type Color =
  | 'primary'
  | 'secondary'
  | 'success'
  | 'info'
  | 'warning'
  | 'error'
  | 'neutral';

const colors: Color[] = [
  'primary',
  'secondary',
  'success',
  'info',
  'warning',
  'error',
  'neutral'
];
const color = ref<Color>('primary');
const icon = ref('i-lucide-check');
const agree = ref<string | number | boolean>(1);
</script>

尺寸與狀態

外框高度對齊同尺寸的輸入框。載入中以同尺寸的轉圈圖示取代勾選框並停用。各狀態的共通行為見共用參數。

<template>
  <ExampleOptions>
    <ExampleOption v-model="size" label="size" :items="sizes" />
    <ExampleOption v-model="state" label="狀態" :items="states" />
  </ExampleOptions>
  <!-- 外框高度對齊同尺寸的輸入框 -->
  <div class="flex items-center gap-x-4">
    <ShuoInputText
      v-model="name"
      class="w-40"
      :size="size"
      :loading="state === '載入中'"
      :disabled="state === '停用'"
      :skeleton="state === '骨架'"
    />
    <ShuoCheckbox
      v-model="agree"
      label="同意條款"
      :size="size"
      :loading="state === '載入中'"
      :disabled="state === '停用'"
      :skeleton="state === '骨架'"
    />
  </div>
</template>

<script setup lang="ts">
type Size = 'xs' | 'sm' | 'md' | 'lg' | 'xl';

const sizes: Size[] = ['xs', 'sm', 'md', 'lg', 'xl'];
const states = ['一般', '停用', '載入中', '骨架'] as const;
const size = ref<Size>('lg');
const state = ref<(typeof states)[number]>('一般');
const name = ref('王小明');
const agree = ref<string | number | boolean>(1);
</script>

範例

與輸入框並排

外層在 flex 中會隨空間收縮並截斷文字。要完整顯示文字，設定 ui.wrapper 為 shrink-0；文字超過容器寬度時仍會截斷並顯示 Tooltip。

<template>
  <div class="flex items-center gap-x-4">
    <ShuoInputNumber v-model="score" :disabled="noScore === 1" class="w-24" />
    <ShuoCheckbox
      v-model="noScore"
      label="此次暫無法評分"
      :ui="{ wrapper: 'shrink-0' }"
    />
  </div>
</template>

<script setup lang="ts">
// 與輸入框並排時，ui.wrapper 設為 shrink-0 讓文字完整顯示。
const score = ref<number | null>(80);
const noScore = ref<string | number | boolean>(0);
</script>

文字旁的輸入框

以 #append 在文字旁放輸入框；輸入框聚焦時呼叫 slot 參數的 check() 一併勾選，labelId 作為輸入框的 aria-labelledby。點擊附加內容的非互動區域不會改變勾選，細節見選項附加內容。

<template>
  <ShuoCheckbox v-model="other" label="其他">
    <!-- 點進說明輸入框時一併勾選 -->
    <template #append="{ labelId, check }">
      <ShuoInputText
        v-model="otherText"
        class="w-48"
        placeholder="請說明"
        :aria-labelledby="labelId"
        @focus="check"
      />
    </template>
  </ShuoCheckbox>
</template>

<script setup lang="ts">
const other = ref<string | number | boolean>(0);
const otherText = ref('');
</script>

必須勾選

同意條款等必須勾選的欄位，以 v.check 檢查綁定值等於 true-value（不用 v.literal，避免 UForm 的 state 型別被限縮）。

<template>
  <UForm
    :schema="schema"
    :state="state"
    class="flex flex-col gap-4"
    @submit="onSubmit"
  >
    <!-- 同意條款 -->
    <UFormField name="agree">
      <ShuoCheckbox
        v-model="state.agree"
        label="我已閱讀並同意服務條款"
        true-value="Y"
        false-value="N"
      />
    </UFormField>

    <div>
      <UButton type="submit" label="送出" />
    </div>
  </UForm>
</template>

<script setup lang="ts">
import * as v from 'valibot';

// 必須勾選：綁定值須等於 true-value。綁定值型別為 string | number | boolean，
// 以 v.check 比對，不用 v.literal（會讓 UForm 的 state 型別只接受 'Y'）。
const schema = v.object({
  agree: v.pipe(
    v.union([v.string(), v.number(), v.boolean()]),
    v.check((value) => value === 'Y', '請勾選同意服務條款')
  )
});
const state = reactive<{ agree: string | number | boolean }>({ agree: 'N' });
const toast = useToast();

const onSubmit = (event: { data: v.InferOutput<typeof schema> }) => {
  toast.add({ title: '送出成功', description: `agree：${event.data.agree}` });
};
</script>

樣式

ui 可用 Nuxt UI UCheckbox 的所有 slot，合併規則見單一元件的 ui prop，另外提供 wrapper：

Slot部位內建樣式
wrapper外層，量測省略文字、掛 Tooltip 並定位載入圖示relative inline-flex w-fit max-w-full min-w-0 align-top
root核取方塊外框（Nuxt UI）w-fit max-w-full min-w-0，高度對齊同尺寸輸入框、垂直置中
label文字（Nuxt UI）truncate
base勾選框（Nuxt UI）載入中為 opacity-0
