選擇

SelectMenu

USelectMenu
下拉選單，可搜尋、多選，文字過長時顯示完整提示。

v-model：單選為選項的 value，多選（multiple）為 value 陣列；清空時的值見 empty-value。

用法

單選與多選

單選綁定選項的 value；multiple 時綁定 value 陣列，已選取的名稱以「、」連接。單選未選取時為 empty-value（預設 ''，可改為 null），多選為 []。

<template>
  <!-- 單選 -->
  <UFormField label="單選">
    <ShuoSelectMenu v-model="type" :items="items" placeholder="請選擇" />
  </UFormField>

  <!-- 多選 -->
  <UFormField label="多選">
    <ShuoSelectMenu
      v-model="types"
      :items="items"
      multiple
      placeholder="請選擇"
    />
  </UFormField>
</template>

<script setup lang="ts">
const items = [
  { label: '一般公告', value: 'general' },
  { label: '系統公告', value: 'system' },
  { label: '作業通知', value: 'notice' }
];
const type = ref('general');
const types = ref<string[]>(['general', 'notice']);
</script>

顯示格式

format 預設 {label}，只顯示名稱。{value}、{label} 會被替換，替換結果不再二次解析，未知標記原樣保留。選項與已選取文字都套用同一格式。

<template>
  <ExampleOptions>
    <ExampleOption v-model="format" label="format" :items="formats" />
  </ExampleOptions>
  <ShuoSelectMenu v-model="code" :items="items" :format="format" />
</template>

<script setup lang="ts">
const formats = ['{label}', '{value}_{label}', '{label}（{value}）', '{value}'];
const format = ref('{value}_{label}');
const items = [
  { label: '一般件', value: 'N01' },
  { label: '急件', value: 'U02' },
  { label: '特急件', value: 'S03' }
];
const code = ref('U02');
</script>

要讓整個專案都顯示「值_名稱」，在全站設定 format：

<ShuoSelectMenu v-model="state.type" :items="items" format="{value}_{label}" />

// nuxt.config.ts
export default defineNuxtConfig({
  shuoUi: {
    components: {
      selectMenu: { format: '{value}_{label}' }
    }
  }
});

自訂選項欄位

後端欄位不是 label、value 時，以 label-key、value-key 指定。USelectMenu 的 description-key 等 props 也能直接使用，欄位名稱依 items 推導，寫錯會有型別錯誤。

<template>
  <ShuoSelectMenu
    v-model="branch"
    :items="branches"
    label-key="Name"
    value-key="Code"
    description-key="Address"
  />
</template>

<script setup lang="ts">
// 後端回傳的欄位名稱不是 label、value 時，
// 以 label-key、value-key 指定，不必先轉換資料。
const branches = [
  { Code: 'TPE', Name: '台北分行', Address: '台北市中正區' },
  { Code: 'TXG', Name: '台中分行', Address: '台中市西區' },
  { Code: 'KHH', Name: '高雄分行', Address: '高雄市前金區' }
];
const branch = ref('TXG');
</script>

搜尋

選單內建搜尋框，提示文字為「關鍵字查詢...」（英文為「Search...」），可由多語系與文案調整。關鍵字查詢依 label-key 欄位比對，不受顯示格式影響。選項很少時可傳 :search-input="false" 隱藏搜尋框。

<template>
  <ExampleOptions>
    <ExampleOption
      v-model="searchInput"
      label="search-input"
      :items="[true, false]"
    />
  </ExampleOptions>
  <!-- 不傳 search-input 時沿用元件內建的搜尋框與提示文字 -->
  <ShuoSelectMenu
    v-model="branch"
    :items="branches"
    v-bind="searchInput ? {} : { searchInput: false }"
    placeholder="請選擇分行"
  />
</template>

<script setup lang="ts">
const searchInput = ref(true);
const branch = ref('');
const branches = [
  { label: '台北分行', value: 'TPE' },
  { label: '新北分行', value: 'NTP' },
  { label: '桃園分行', value: 'TYN' },
  { label: '新竹分行', value: 'HSZ' },
  { label: '台中分行', value: 'TXG' },
  { label: '台南分行', value: 'TNN' },
  { label: '高雄分行', value: 'KHH' },
  { label: '花蓮分行', value: 'HUN' }
];
</script>

尺寸與狀態

載入中以轉圈圖示取代右側箭頭並停用選單。切換骨架、停用或載入中時會關閉已開啟的選單，還原後不自動重開。各狀態的共通行為見共用參數。

<template>
  <ExampleOptions>
    <ExampleOption v-model="size" label="size" :items="sizes" />
    <ExampleOption v-model="state" label="狀態" :items="states" />
  </ExampleOptions>
  <ShuoSelectMenu
    v-model="type"
    :items="['一般公告', '系統公告', '作業通知']"
    :size="size"
    :loading="state === '載入中'"
    :disabled="state === '停用'"
    :skeleton="state === '骨架'"
  />
</template>

<script setup lang="ts">
type Size = 'xs' | 'sm' | 'md' | 'lg' | 'xl';

const sizes: Size[] = ['xs', 'sm', 'md', 'lg', 'xl'];
const states = ['一般', '停用', '載入中', '骨架'] as const;
const size = ref<Size>('lg');
const state = ref<(typeof states)[number]>('一般');
const type = ref('一般公告');
</script>

範例

搭配表單驗證

單選未選取為 ''，用 requiredText；多選未選取為 []，用 requiredArray。

<template>
  <UForm
    :schema="schema"
    :state="state"
    class="flex flex-col gap-4"
    @submit="onSubmit"
  >
    <!-- 公告類別 -->
    <UFormField label="公告類別" name="type" required>
      <ShuoSelectMenu
        v-model="state.type"
        :items="types"
        placeholder="請選擇"
      />
    </UFormField>

    <!-- 發送對象 -->
    <UFormField label="發送對象" name="targets" required>
      <ShuoSelectMenu
        v-model="state.targets"
        :items="targets"
        multiple
        placeholder="可複選"
      />
    </UFormField>

    <div>
      <UButton type="submit" label="送出" />
    </div>
  </UForm>
</template>

<script setup lang="ts">
import * as v from 'valibot';

// 單選未選取為 ''，用 requiredText；多選未選取為 []，用 requiredArray。
const schema = v.object({
  type: requiredText('公告類別'),
  targets: requiredArray('發送對象', v.string())
});
const state = reactive<{ type: string; targets: string[] }>({
  type: '',
  targets: []
});
const types = [
  { label: '一般公告', value: 'general' },
  { label: '系統公告', value: 'system' }
];
const targets = [
  { label: '全體員工', value: 'all' },
  { label: '主管', value: 'manager' },
  { label: '外部廠商', value: 'vendor' }
];
const toast = useToast();

const onSubmit = (event: { data: v.InferOutput<typeof schema> }) => {
  const { type, targets } = event.data;
  toast.add({
    title: '送出成功',
    description: `${type}：${(targets ?? []).join('、')}`
  });
};
</script>

長文字省略提示

已選取文字超過寬度時以省略號截斷，滑鼠移入或聚焦時以 Tooltip 顯示完整文字，觸控裝置長按顯示（見 Tooltip），長按不會開啟選單；選單開啟時不顯示。寬度設定在 ui.wrapper，見下方樣式。

<template>
  <ExampleOptions>
    <ExampleOption v-model="width" label="ui.wrapper" :items="widths" />
  </ExampleOptions>
  <ShuoSelectMenu
    v-model="selected"
    :items="items"
    multiple
    :ui="{ wrapper: width }"
  />
</template>

<script setup lang="ts">
const widths = ['w-48', 'w-72', 'w-full'];
const width = ref('w-48');
const items = [
  { label: '台北市中正區重慶南路一段', value: 'A01' },
  { label: '新北市板橋區中山路一段', value: 'A02' },
  { label: '台中市西屯區台灣大道三段', value: 'A03' }
];
const selected = ref<string[]>(['A01', 'A02']);
</script>

非同步載入選項

向後端查詢選項時以 loading 顯示轉圈圖示並停用選單，查詢完成後填入 items。綁定值找不到對應選項時顯示 placeholder，選項回來後自動顯示名稱。

<template>
  <ExampleOptions>
    <ExampleAction
      label="重新載入選項"
      icon="i-lucide-refresh-cw"
      :action="loadBranches"
    />
  </ExampleOptions>
  <ShuoSelectMenu
    v-model="branch"
    :items="branches"
    :loading="loading"
    placeholder="請選擇分行"
  />
</template>

<script setup lang="ts">
type Branch = { label: string; value: string };

const branch = ref('TXG');
const branches = ref<Branch[]>([]);
const loading = ref(false);

// 模擬向後端查詢選項；查詢期間顯示轉圈圖示並停用選單。
const loadBranches = async () => {
  loading.value = true;
  await new Promise((resolve) => setTimeout(resolve, 1500));
  branches.value = [
    { label: '台北分行', value: 'TPE' },
    { label: '台中分行', value: 'TXG' },
    { label: '高雄分行', value: 'KHH' }
  ];
  loading.value = false;
};

onMounted(loadBranches);
</script>

連動選單

縣市改變時清空區域，區域的 items 由縣市計算。

<template>
  <div class="grid gap-4 sm:grid-cols-2">
    <!-- 縣市 -->
    <UFormField label="縣市">
      <ShuoSelectMenu v-model="city" :items="cities" placeholder="請選擇縣市" />
    </UFormField>

    <!-- 區域 -->
    <UFormField label="區域">
      <ShuoSelectMenu
        v-model="district"
        :items="districts"
        :disabled="!city"
        placeholder="請先選擇縣市"
      />
    </UFormField>
  </div>
</template>

<script setup lang="ts">
const districtsByCity: Record<string, string[]> = {
  台北市: ['中正區', '大安區', '信義區'],
  台中市: ['西區', '西屯區', '北屯區'],
  高雄市: ['前金區', '苓雅區', '左營區']
};
const cities = Object.keys(districtsByCity);
const city = ref('');
const district = ref('');
const districts = computed(() => districtsByCity[city.value] ?? []);

// 縣市改變時清空區域，避免留下不屬於新縣市的值。
watch(city, () => {
  district.value = '';
});
</script>

開啟選單

透過 template ref 的 triggerRef 取得觸發按鈕，呼叫 click() 開啟選單。

<template>
  <ExampleOptions>
    <ExampleAction
      label="展開選單"
      icon="i-lucide-chevrons-up-down"
      :action="() => field?.triggerRef?.click()"
    />
  </ExampleOptions>
  <ShuoSelectMenu ref="field" v-model="type" :items="types" />
</template>

<script setup lang="ts">
const types = ['一般公告', '系統公告', '作業通知'];
const type = ref('一般公告');
const field = useTemplateRef('field');
</script>

Slots

USelectMenu 的 slot 全部可用（leading、trailing、item、item-leading、content-top 等）。以下三個有傳入時取代元件的內建內容：

Slot內建內容
item-label依 format 格式化的選項文字
default依 format 格式化的已選取文字
empty「無可用選項」（依語系）

Expose

名稱型別說明
triggerRefHTMLButtonElement | null觸發按鈕
viewportRefHTMLDivElement | null選單捲動區域

樣式

ui 可用 Nuxt UI USelectMenu 的所有 slot，另外提供 wrapper：

Slot部位內建樣式
wrapper外層，量測省略文字並掛 Tooltipflex w-full min-w-0
base觸發按鈕（Nuxt UI）w-full min-w-0
value、placeholder已選取文字、提示文字（Nuxt UI）min-w-0 truncate

要縮短寬度時設定 ui.wrapper（例如 w-40），觸發按鈕會填滿外層；class 落在觸發按鈕，不影響外層。ui.value、ui.placeholder 在已選取、未選取與找不到選項時都套用。
