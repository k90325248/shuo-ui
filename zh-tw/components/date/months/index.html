日期與期間

Months

UInput
年月數換算輸入，可同時綁定總月數、年數與月數。

v-model: number | null（總月數），另有 v-model:year、v-model:month，見下方 v-model。顯示「年輸入框 年 月輸入框 月」。

用法

年月換算

v-model 是總月數，v-model:year、v-model:month 是拆分後的年數與月數（0～11），三個綁定互相同步。

年月
年
月
<template>
  <ExampleOptions>
    <ExampleAction
      label="回填總月數 15"
      icon="i-lucide-hash"
      :action="() => (total = 15)"
    />
    <ExampleAction
      label="回填 1 年 15 月"
      icon="i-lucide-calendar-range"
      :action="fillYearMonth"
    />
    <ExampleAction
      label="清空"
      icon="i-lucide-eraser"
      :action="() => (total = null)"
    />
  </ExampleOptions>
  <ShuoMonths v-model="total" v-model:year="years" v-model:month="months" />
</template>

<script setup lang="ts">
// 三個綁定互相同步；輸入 0 年 13 月後離開欄位，會進位成 1 年 1 月。
const total = ref<number | null>(30);
const years = ref<number | null>(null);
const months = ref<number | null>(null);

// 只回填年月時重新合計，月份超過 11 會進位成 2 年 3 月。
const fillYearMonth = () => {
  years.value = 1;
  months.value = 15;
};
</script>
  • 只接受非負整數；焦點離開年月整組後才進位（在年與月之間移動焦點不提交，可同時清空兩欄）：0 年 13 月變成 1 年 1 月，總月數 13。
  • 三個綁定可單獨或同時使用。父層同時回填總月數與年月且內容衝突時，總月數優先；只回填年月時重新合計並進位。
  • 單邊空白視為 0，兩邊皆空則三個綁定皆為 null。父層回填字串、負數、小數、NaN 或超出安全整數的值時視為空值。

窄容器

容器寬度不足以顯示年月兩欄時，自動改為單一「總月數」輸入框；寬度足夠時恢復年月兩欄，尚未離開焦點的輸入會保留。

<template>
  <ExampleOptions>
    <ExampleOption v-model="width" label="容器寬度" :items="widths" />
  </ExampleOptions>
  <div :class="width === '足夠' ? 'w-64' : 'w-24'">
    <ShuoMonths v-model="total" />
  </div>
</template>

<script setup lang="ts">
const widths = ['足夠', '不足'] as const;
const width = ref<(typeof widths)[number]>('不足');
const total = ref<number | null>(30);
</script>

尺寸與狀態

載入中在「月」後方顯示轉圈圖示並停用輸入。「年」「月」單位依語系切換（英文為「yr」「mo」），寬度隨文字延伸，完整年月所需的寬度也跟著調整。各狀態的共通行為見共用參數。

<template>
  <ExampleOptions>
    <ExampleOption v-model="size" label="size" :items="sizes" />
    <ExampleOption v-model="state" label="狀態" :items="states" />
  </ExampleOptions>
  <ShuoMonths
    v-model="total"
    :size="size"

    :disabled="state === '停用'"

  />
</template>

<script setup lang="ts">
type Size = 'xs' | 'sm' | 'md' | 'lg' | 'xl';

const sizes: Size[] = ['xs', 'sm', 'md', 'lg', 'xl'];
const states = ['一般', '停用', '載入中', '骨架'] as const;
const size = ref<Size>('lg');
const state = ref<(typeof states)[number]>('一般');
const total = ref<number | null>(30);
</script>

範例

搭配表單驗證

綁定總月數，必填用 requiredNumber，上下限另以 v.minValue、v.maxValue 檢查。

年月
年
月
<template>
  <UForm
    :schema="schema"
    :state="state"
    class="flex flex-col gap-4"
    @submit="onSubmit"
  >
    <!-- 貸款期間 -->
    <UFormField label="貸款期間" name="term" required>
      <ShuoMonths v-model="state.term" />
    </UFormField>

    <div>
      <UButton type="submit" label="送出" />
    </div>
  </UForm>
</template>

<script setup lang="ts">
import * as v from 'valibot';

// 必填用 requiredNumber，上下限另以 v.minValue、v.maxValue 檢查。
const schema = v.object({
  term: v.pipe(
    requiredNumber('貸款期間'),
    v.minValue(1, '貸款期間 至少 1 個月'),
    v.maxValue(360, '貸款期間 不可超過 30 年')
  )
});
const state = reactive({ term: null as number | null });
const toast = useToast();

const onSubmit = (event: { data: v.InferOutput<typeof schema> }) => {
  toast.add({ title: '送出成功', description: `${event.data.term} 個月` });
};
</script>

只綁定年月

API 的年資分成年、月兩個欄位時，只綁 v-model:year、v-model:month。

年
月
<template>
  <!-- 工作年資 -->
  <UFormField label="工作年資">
    <ShuoMonths v-model:year="form.workYears" v-model:month="form.workMonths" />
  </UFormField>

  <div>
    <UButton label="儲存" icon="i-lucide-save" @click="save" />
  </div>
</template>

<script setup lang="ts">
// API 的年資分成年、月兩個欄位，只綁 year、month 即可。
const form = reactive({
  workYears: 3 as number | null,
  workMonths: 5 as number | null
});
const toast = useToast();

const save = () => {
  toast.add({
    title: '已儲存',
    description: `workYears：${form.workYears}，workMonths：${form.workMonths}`
  });
};
</script>

—見樣式

size、disabled、loading、skeleton、name 的行為見共用參數；id 指向年數框，窄容器時為總月數框。

樣式

ui 合併規則見單一元件的 ui prop；year、month、total 的值同 Nuxt UI UInput 的 ui：

Slot部位內建樣式
root外層inline-flex items-center gap-2，寬度為完整年月所需寬度，字級依尺寸
year、month年數、月數輸入框root 容納兩位數的寬度；base 為 text-center tabular-nums
total窄容器時的總月數輸入框root 容納四位數的寬度；base 為 text-center tabular-nums
unit「年」「月」文字min-w-[1em] flex-none whitespace-nowrap
<ShuoMonths
  v-model="totalMonths"
  class="w-80"
  :ui="{ unit: 'text-muted', year: { base: 'text-left' } }"
/>

外層的 class 與 ui.root 一起合併，可覆寫寬度；寬度小於完整年月所需時會改為總月數輸入。
