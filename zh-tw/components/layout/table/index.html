查詢頁版面

Table

UTable
基於 UTable 的純表格，含骨架、空資料與高度過渡。

沒有卡片、標題與分頁，可直接放進彈窗或自己的 UCard。表頭不換行、儲存格內距、空資料與查詢中文字、初次載入骨架、interactionDisabled，以及高度與淡化過渡，都與 ShuoListCard 共用。泛型 T 為資料列型別。

用法

查詢中與空資料

loading 表示正在查詢。已有資料時重新查詢，資料淡化並以高度過渡切換；沒有資料時查詢顯示「查詢中…」。清空資料後顯示 empty，預設「查無資料」。

項目金額
房屋貸款3,200,000
信用貸款450,000
汽車貸款680,000
<template>
  <ExampleOptions>
    <ExampleOption
      v-model="empty"
      label="empty"
      :items="['查無資料', '沒有符合條件的貸款']"
    />
    <ExampleAction
      label="重新查詢"
      icon="i-lucide-refresh-cw"
      :action="reload"
    />
    <ExampleAction
      label="清空資料"
      icon="i-lucide-eraser"
      :action="() => (rows = [])"
    />
  </ExampleOptions>
  <ShuoTable
    :data="rows"
    :columns="columns"
    :loading="loading"
    :empty="empty"
  />
</template>

<script setup lang="ts">
import type { TableColumn } from '@nuxt/ui';

interface Row {
  item: string;
  amount: string;
}

const columns: TableColumn<Row>[] = [
  { accessorKey: 'item', header: '項目' },
  { accessorKey: 'amount', header: '金額' }
];
const source: Row[] = [
  { item: '房屋貸款', amount: '3,200,000' },
  { item: '信用貸款', amount: '450,000' },
  { item: '汽車貸款', amount: '680,000' }
];
const empty = ref('查無資料');
const rows = ref<Row[]>([...source]);
const loading = ref(false);

// 重新查詢且已有資料時，資料淡化並以高度過渡切換到新內容。
const reload = async () => {
  loading.value = true;
  await new Promise((resolve) => setTimeout(resolve, 800));
  rows.value = source.slice(0, Math.floor(Math.random() * 3) + 1);
  loading.value = false;
};
</script>

重新查詢期間請保留原本的 data，查詢成功後再更新，資料才會淡化而不是清空。

初次載入骨架

元件建立時即在查詢（loading 為 true）且沒有資料時，依欄位數顯示三列骨架；第一次查詢結束後不再顯示骨架。按「重新建立」以查詢中的狀態重新建立表格。

案件編號申請人金額
查無資料
<template>
  <ExampleOptions>
    <ExampleAction label="重新建立" icon="i-lucide-play" :action="recreate" />
  </ExampleOptions>
  <ShuoTable
    :key="version"
    :data="rows"
    :columns="columns"
    :loading="loading"
  />
</template>

<script setup lang="ts">
import type { TableColumn } from '@nuxt/ui';

interface Row {
  id: string;
  applicant: string;
  amount: string;
}

const columns: TableColumn<Row>[] = [
  { accessorKey: 'id', header: '案件編號' },
  { accessorKey: 'applicant', header: '申請人' },
  { accessorKey: 'amount', header: '金額' }
];
const version = ref(0);
const rows = ref<Row[]>([]);
const loading = ref(false);

// 元件建立時已在查詢且沒有資料，才顯示骨架列；查詢結束後不再出現。
const recreate = async () => {
  rows.value = [];
  loading.value = true;
  version.value++;
  await new Promise((resolve) => setTimeout(resolve, 1500));
  rows.value = [
    { id: 'A0001', applicant: '王小明', amount: '3,200,000' },
    { id: 'A0002', applicant: '陳美玲', amount: '450,000' }
  ];
  loading.value = false;
};

onMounted(recreate);
</script>

骨架欄數以葉節點欄位計算，並排除 tableProps.state.columnVisibility 隱藏的欄位。

過渡

資料筆數或內容高度改變時，資料區高度以 0.2 秒平滑變化；重新查詢且已有資料時，資料淡化為 0.5。transition 設為 false 時高度直接跟著內容，淡化不播放過渡。使用者偏好減少動態效果時一律不播放。

序號項目
1第 1 期繳款
2第 2 期繳款
<template>
  <ExampleOptions>
    <ExampleOption
      v-model="transition"
      label="transition"
      :items="[true, false]"
    />
    <ExampleAction label="增加一筆" icon="i-lucide-list-plus" :action="add" />
    <ExampleAction
      label="移除一筆"
      icon="i-lucide-list-minus"
      :action="() => rows.pop()"
    />
    <ExampleAction
      label="重新查詢"
      icon="i-lucide-refresh-cw"
      :action="reload"
    />
  </ExampleOptions>
  <ShuoTable
    :data="rows"
    :columns="columns"
    :loading="loading"
    :transition="transition"
  />
</template>

<script setup lang="ts">
import type { TableColumn } from '@nuxt/ui';

interface Row {
  no: number;
  item: string;
}

const columns: TableColumn<Row>[] = [
  { accessorKey: 'no', header: '序號' },
  { accessorKey: 'item', header: '項目' }
];
const transition = ref(true);
const rows = ref<Row[]>([
  { no: 1, item: '第 1 期繳款' },
  { no: 2, item: '第 2 期繳款' }
]);
const loading = ref(false);

const add = () => {
  const no = rows.value.length + 1;
  rows.value.push({ no, item: `第 ${no} 期繳款` });
};

// 查詢期間保留原資料，資料區淡化。
const reload = async () => {
  loading.value = true;
  await new Promise((resolve) => setTimeout(resolve, 800));
  loading.value = false;
};
</script>

勾選

selectable 開啟後在最前面加上勾選欄，勾選結果以 v-model:selected 綁定 key 陣列。row-key 指定 key，可以是欄位名稱（例如 row-key="id"），或由整筆資料組出 key 的函式，勾選結果保留 key 原本的型別。表頭的全選只勾選目前這頁可勾選的資料，只勾了一部分時顯示半選；select-all 設為 false 時不顯示全選，改顯示 selection-header 的文字。

案號申請人金額
A001王小明12,500
A002李小華8,000
A003陳大同30,000
<template>
  <ExampleOptions>
    <ExampleOption
      v-model="selectAll"
      label="select-all"
      :items="[true, false]"
    />
    <ExampleAction
      label="匯出勾選"
      icon="i-lucide-download"
      :action="exportSelected"
    />
    <ExampleAction
      label="清空勾選"
      icon="i-lucide-x"
      :action="() => (selected = [])"
    />
  </ExampleOptions>
  <ShuoTable
    v-model:selected="selected"
    :data="rows"
    :columns="columns"
    selectable
    :select-all="selectAll"
    selection-header="選取"
    row-key="id"
  />
</template>

<script setup lang="ts">
import type { TableColumn } from '@nuxt/ui';

interface Row {
  id: string;
  name: string;
  amount: string;
}

const columns: TableColumn<Row>[] = [
  { accessorKey: 'id', header: '案號' },
  { accessorKey: 'name', header: '申請人' },
  { accessorKey: 'amount', header: '金額' }
];
const rows: Row[] = [
  { id: 'A001', name: '王小明', amount: '12,500' },
  { id: 'A002', name: '李小華', amount: '8,000' },
  { id: 'A003', name: '陳大同', amount: '30,000' }
];
const selectAll = ref(true);
// 勾選結果為 row-key 指定欄位的值。
const selected = ref<string[]>([]);
const toast = useToast();

const exportSelected = () => {
  if (!selected.value.length) {
    toast.add({ color: 'error', title: '至少需勾選一筆' });
    return;
  }
  toast.add({ title: '匯出', description: selected.value.join('、') });
};
</script>
  • 未設定 row-key 時以列序號（'0'、'1'…）為 key，換頁後第一列仍是 '0'，會勾到不同的資料，後端分頁時請務必設定。
  • 換頁或重新查詢時保留已勾選的 key，包含不在目前資料中的其他頁；要取消所有勾選時把 v-model:selected 設為 []。
  • 查詢中（loading）停用所有核取方塊。
  • select-all 可在全站元件預設值以 components.table.selectAll 統一設定。

不可勾選的資料

row-selectable 回傳 false 的資料停用勾選，全選時也會略過。範例的 key 由年度與序號組成（例如 115-1），已結案的資料不可勾選。

年度序號狀態
1151審核中
1152已結案
1153審核中
1141已結案
<template>
  <ShuoTable
    v-model:selected="selected"
    :data="rows"
    :columns="columns"
    selectable
    :row-key="(row) => `${row.year}-${row.no}`"
    :row-selectable="(row) => row.status !== '已結案'"
  />
</template>

<script setup lang="ts">
import type { TableColumn } from '@nuxt/ui';

interface Row {
  year: number;
  no: number;
  status: string;
}

const columns: TableColumn<Row>[] = [
  { accessorKey: 'year', header: '年度' },
  { accessorKey: 'no', header: '序號' },
  { accessorKey: 'status', header: '狀態' }
];
const rows: Row[] = [
  { year: 115, no: 1, status: '審核中' },
  { year: 115, no: 2, status: '已結案' },
  { year: 115, no: 3, status: '審核中' },
  { year: 114, no: 1, status: '已結案' }
];
// key 由年度與序號組成，例如 115-1。
const selected = ref<string[]>([]);
</script>

彈窗內的明細表

限制高度並固定表頭時，用 tableProps 設定 ui.root 與 sticky，捲動發生在表格本身，表頭才會固定。彈窗每次開啟時表格重新建立，查詢期間顯示骨架列。

<template>
  <UModal title="繳款明細" @update:open="(open) => open && load()">
    <UButton label="開啟明細" icon="i-lucide-table-2" variant="soft" />
    <template #body>
      <ShuoTable
        :data="rows ?? []"
        :columns="columns"
        :loading="!rows"
        :table-props="{ sticky: true, ui: { root: 'max-h-80' } }"
      />
    </template>
  </UModal>
</template>

<script setup lang="ts">
import type { TableColumn } from '@nuxt/ui';

interface Row {
  no: number;
  date: string;
  amount: string;
}

const columns: TableColumn<Row>[] = [
  { accessorKey: 'no', header: '期數' },
  { accessorKey: 'date', header: '繳款日' },
  { accessorKey: 'amount', header: '金額' }
];
// null 代表尚未取得資料；彈窗內的表格建立時即在查詢，先顯示骨架列。
const rows = ref<Row[] | null>(null);

// 每次開啟重新查詢，模擬後端需要 0.8 秒。
const load = async () => {
  rows.value = null;
  await new Promise((resolve) => setTimeout(resolve, 800));
  rows.value = Array.from({ length: 24 }, (_, index) => ({
    no: index + 1,
    date: `2026/${String((index % 12) + 1).padStart(2, '0')}/10`,
    amount: '12,500'
  }));
};
</script>

勾選欄樣式

checkbox-props 設定全選與每列核取方塊的外觀，兩者共用同一份設定。勾選欄格子的寬度與對齊則以 columns 中 id 為 select 的欄位設定，見勾選欄位置與自訂勾選格。

案號申請人
A001王小明
A002李小華
A003陳大同
<template>
  <ShuoTable
    v-model:selected="selected"
    :data="rows"
    :columns="columns"
    selectable
    row-key="id"
    :checkbox-props="{
      class: 'justify-center',
      color: 'neutral',
      size: 'lg',
      icon: 'i-lucide-check-check',
      ui: { base: 'rounded-full' }
    }"
  />
</template>

<script setup lang="ts">
import type { TableColumn } from '@nuxt/ui';

interface Row {
  id: string;
  name: string;
}

const columns: TableColumn<Row>[] = [
  // 勾選欄的格子：放寬並置中
  { id: 'select', meta: { class: { th: 'w-16', td: 'w-16' } } },

  { accessorKey: 'id', header: '案號' },
  { accessorKey: 'name', header: '申請人' }
];
const rows: Row[] = [
  { id: 'A001', name: '王小明' },
  { id: 'A002', name: '李小華' },
  { id: 'A003', name: '陳大同' }
];
const selected = ref<string[]>(['A002']);
</script>
屬性型別說明
classany核取方塊外層（UCheckbox 的 root）的 class
uiUCheckbox 的 ui各部位樣式：root、container、base（方框）、indicator（勾選底色）、icon 等，與 UCheckbox 的主題合併；可用函式取得預設值後自行取代
color'primary'、'neutral' 等主題色勾選後的底色，未設定時為 primary
size'xs'、'sm'、'md'、'lg'、'xl'方框尺寸，未設定時為 md
iconstring勾選時的圖示，未設定時沿用 Nuxt UI 的 check 圖示
indeterminateIconstring半選時的圖示，未設定時沿用 Nuxt UI 的 minus 圖示
  • 型別為 TableCheckboxProps，可由 #shuo-ui/components/ShuoTable.vue 匯入。
  • 勾選狀態、停用與無障礙名稱由表格控制，不能透過 checkbox-props 設定；variant 的 card 樣式不適合放在表格內，也不開放。
  • 全選與每列要不同外觀時，以 #select-header 或 #select-cell 插槽自行放 UCheckbox。
  • 可在全站元件預設值以 components.table.checkboxProps 統一設定（不能寫函式）。頁面明確傳入 checkbox-props 時整個取代全站設定，不逐項合併。

勾選欄位置與自訂勾選格

勾選欄預設放在最前面。要放在其他位置時，在 columns 加上 id 為 select 的欄位，勾選欄就放在該位置，這個欄位的設定也會套用到勾選欄；meta.class 的 th、td 會分別取代內建的 w-px（貼合核取方塊的寬度），只寫 td 時表頭仍為 w-px。

const columns: TableColumn<Row>[] = [
  { accessorKey: 'name', header: '名稱' },

  // 勾選欄放在名稱後面
  { id: 'select', meta: { class: { td: 'bg-muted' } } },

  { accessorKey: 'amount', header: '金額' }
];

#select-header、#select-cell 插槽可取代內建的全選與核取方塊，參數與 UTable 相同，例如以 row.getIsSelected() 取得勾選狀態、row.toggleSelected() 切換勾選、row.getCanSelect() 判斷是否可勾選。

falseboolean
selectAll

開啟勾選時表頭是否顯示全選，只勾選目前這頁可勾選的資料

trueboolean
selectionHeader

關閉全選時的勾選欄表頭文字

''（依語系）string
tableProps

額外 Table 設定

—Partial<TableProps<TableData>>
transition

是否在高度變化與重新查詢淡化時播放過渡

trueboolean

tableProps.paginationOptions.manualPagination 固定為 true，分頁由後端處理；欄位顯示取自 tableProps.state.columnVisibility，直接傳入的 tableProps.columnVisibility 不會生效。

開啟 selectable 時，勾選狀態由 v-model:selected 控制，tableProps 的 rowSelection 與 onUpdate:rowSelection 不會生效；未開啟時仍可照 UTable 的寫法自行以 tableProps 控制勾選。row-key 未開啟勾選時也會作為 UTable 的 getRowId。

「查詢中…」與「查無資料」依語系切換（英文為「Loading…」「No data」），可由文案 table.loading、table.empty 全域覆寫，見多語系與文案；全選與每列核取方塊的無障礙名稱（「全選」「選取此列」）及關閉全選時的表頭文字（預設空白）由 table.selectAll、table.selectRow、table.selectionHeader 設定。表頭、儲存格等樣式用 tableProps.ui 設定，與內建樣式合併。
