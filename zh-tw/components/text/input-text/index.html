文字與數字

InputText

UInput
單行文字輸入，可遮蔽全部或最後幾碼。

v-model: string。

用法

遮蔽

mask 為 true 時全部遮蔽，正整數遮蔽最後指定碼數。右側眼睛按鈕切換明碼與遮蔽，hide-mask-toggle 可隱藏這個按鈕；v-model 始終保留原始文字。

A123456789••••
<template>
  <ExampleOptions>
    <ExampleOption v-model="mask" label="mask" :items="[4, 2, true, false]" />
    <ExampleOption
      v-model="hideMaskToggle"
      label="hide-mask-toggle"
      :items="[false, true]"
    />
  </ExampleOptions>
  <ShuoInputText
    v-model="idNumber"
    :mask="mask"
    :hide-mask-toggle="hideMaskToggle"
  />
</template>

<script setup lang="ts">
const mask = ref<number | boolean>(4);
const hideMaskToggle = ref(false);
const idNumber = ref('A123456789');
</script>
  • 12345678 搭配 :mask="4" 顯示 1234••••；不足四碼時全部遮蔽。false、0、負數與非有限數字不啟用，小數向下取整。
  • 遮蔽狀態禁止複製及剪下，顯示明碼後可正常複製。
  • 動態變更 mask 或 hideMaskToggle 會重設為遮蔽狀態。
  • 以 ui.base 改變文字對齊時，局部遮蔽的顯示層跟著對齊。

切換按鈕圖示

reveal-icon 是遮蔽中顯示的圖示（按下顯示明碼），conceal-icon 是顯示明碼時的圖示（按下恢復遮蔽）。

<template>
  <ExampleOptions>
    <ExampleOption
      v-model="revealIcon"
      label="reveal-icon"
      :items="['i-lucide-eye', 'i-lucide-lock', 'i-lucide-scan-eye']"
    />
    <ExampleOption
      v-model="concealIcon"
      label="conceal-icon"
      :items="['i-lucide-eye-off', 'i-lucide-lock-open', 'i-lucide-scan']"
    />
  </ExampleOptions>
  <ShuoInputText
    v-model="password"
    :mask="true"
    :reveal-icon="revealIcon"
    :conceal-icon="concealIcon"
  />
</template>

<script setup lang="ts">
const revealIcon = ref('i-lucide-eye');
const concealIcon = ref('i-lucide-eye-off');
const password = ref('secret123');
</script>

外觀

沿用 UInput 的 variant、color 與 highlight。

<template>
  <ExampleOptions>
    <ExampleOption v-model="variant" label="variant" :items="variants" />
    <ExampleOption v-model="color" label="color" :items="colors" />
    <ExampleOption
      v-model="highlight"
      label="highlight"
      :items="[false, true]"
    />
  </ExampleOptions>
  <ShuoInputText
    v-model="name"
    :variant="variant"
    :color="color"
    :highlight="highlight"
    placeholder="請輸入姓名"
  />
</template>

<script setup lang="ts">
type Variant = 'outline' | 'soft' | 'subtle' | 'ghost' | 'none';
type Color =
  | 'primary'
  | 'secondary'
  | 'success'
  | 'info'
  | 'warning'
  | 'error'
  | 'neutral';

const variants: Variant[] = ['outline', 'soft', 'subtle', 'ghost', 'none'];
const colors: Color[] = [
  'primary',
  'secondary',
  'success',
  'info',
  'warning',
  'error',
  'neutral'
];
const variant = ref<Variant>('outline');
const color = ref<Color>('primary');
const highlight = ref(false);
const name = ref('');
</script>

const icon = ref('i-lucide-search');

const keyword = ref('');
</script>

尺寸與狀態

停用時仍可切換明碼顯示；骨架期間不可操作。各狀態的共通行為見共用參數。

A123456789••••
<template>
  <ExampleOptions>
    <ExampleOption v-model="size" label="size" :items="sizes" />
    <ExampleOption v-model="state" label="狀態" :items="states" />
  </ExampleOptions>
  <ShuoInputText
    v-model="text"
    :mask="4"
    :size="size"
    :loading="state === '載入中'"
    :disabled="state === '停用'"
    :skeleton="state === '骨架'"
  />
</template>

<script setup lang="ts">
type Size = 'xs' | 'sm' | 'md' | 'lg' | 'xl';

const sizes: Size[] = ['xs', 'sm', 'md', 'lg', 'xl'];
const states = ['一般', '停用', '載入中', '骨架'] as const;
const size = ref<Size>('lg');
const state = ref<(typeof states)[number]>('一般');
const text = ref('A123456789');
</script>

範例

搭配表單驗證

必填用 requiredText，格式另外以 v.regex 檢查。遮蔽只影響顯示，驗證與送出的都是原始文字。

<template>
  <UForm
    :schema="schema"
    :state="state"
    class="flex flex-col gap-4"
    @submit="onSubmit"
  >
    <!-- 身分證字號 -->
    <UFormField label="身分證字號" name="idNumber" required>
      <ShuoInputText
        v-model="state.idNumber"
        :mask="4"
        placeholder="A123456789"
      />
    </UFormField>

    <div>
      <UButton type="submit" label="送出" />
    </div>
  </UForm>
</template>

<script setup lang="ts">
import * as v from 'valibot';

// 必填由 requiredText 處理，格式另以 v.regex 檢查；遮蔽不影響驗證的值。
const schema = v.object({
  idNumber: v.pipe(
    requiredText('身分證字號'),
    v.regex(/^[A-Z][12]\d{8}$/, '身分證字號格式不正確')
  )
});
const state = reactive({ idNumber: '' });
const toast = useToast();

const onSubmit = (event: { data: v.InferOutput<typeof schema> }) => {
  toast.add({ title: '送出成功', description: event.data.idNumber });
};
</script>

      <UIcon name="i-lucide-landmark" class="text-dimmed size-5" />
    </template>
  </ShuoInputText>

<script setup lang="ts">
const account = ref('0123456789012');
</script>

清除按鈕

以 #trailing 放入清除按鈕。有遮蔽或載入中時，尾端優先顯示眼睛按鈕或載入圖示，見下方 Slots。

<template>
  <ShuoInputText
    v-model="keyword"
    icon="i-lucide-search"
    placeholder="輸入關鍵字"
  >
    <template v-if="keyword" #trailing>
      <UButton
        icon="i-lucide-x"
        size="xs"
        color="neutral"
        variant="link"
        aria-label="清除"
        @click="keyword = ''"
      />
    </template>
  </ShuoInputText>
</template>

<script setup lang="ts">
const keyword = ref('Nuxt UI');
</script>

操作原生 input

透過 template ref 的 inputRef 取得原生 input。

<template>
  <ExampleOptions>
    <ExampleAction
      label="聚焦並全選"
      icon="i-lucide-text-select"
      :action="focusAll"
    />
  </ExampleOptions>
  <ShuoInputText ref="field" v-model="text" />
</template>

<script setup lang="ts">
const text = ref('透過 inputRef 操作原生 input');
const field = useTemplateRef('field');

const focusAll = () => {
  field.value?.inputRef?.focus();
  field.value?.inputRef?.select();
};
</script>

Slot參數說明

名稱型別說明

樣式

ui 可用 Nuxt UI UInput 的所有 slot，與內建樣式合併，見單一元件的 ui prop：

Slot部位內建樣式
root外框（Nuxt UI）w-full min-w-0
trailing尾端內容外層（Nuxt UI）有遮蔽時為 pointer-events-auto，讓眼睛按鈕可點擊

class 在 ui.root 之後合併，可覆寫寬度與最小寬度（例如 class="min-w-20"）。
