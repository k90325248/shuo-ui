# v1.0.1

> 發佈於 2026年10月25日

> `1.0.0` 在未安裝 `@iconify-json/lucide` 的專案中無法建置，已撤回，請直接使用 `1.0.1`。本版內容即第一個正式版本，並包含下方的修正。

Shuo UI 第一個正式版本：依照我們專案的表單寫法整理出來的 [Nuxt UI](https://ui.nuxt.com) 元件，以 Nuxt Module 提供，共 15 個元件。完整說明與可操作的範例見[文件網站](https://k90325248.github.io/shuo-ui/)。

## ✨ Highlights

### 🧩 建立在 Nuxt UI 之上

元件包裝 Nuxt UI，沒有另外宣告的 Nuxt UI 參數、slot 與 ref 都能直接使用，型別也會一併推導，照 Nuxt UI 文件使用即可：[沿用 Nuxt UI](https://k90325248.github.io/shuo-ui/components/overview/common#%E6%B2%BF%E7%94%A8-nuxt-ui)

```vue
<ShuoInputText v-model="keyword" variant="soft" icon="i-lucide-search" />
```

### 🇹🇼 繁體中文與台灣常用格式

文案預設繁體中文，並內建專案中常見的格式：身分證字號遮蔽、金額千分位、民國年日期、區碼與電話、年月數換算。綁定值維持原始資料（西元日期、純數字），只在顯示時轉換。

```vue
<ShuoInputText v-model="idNumber" :mask="4" />
<ShuoInputNumber v-model="amount" unit />
<!-- 顯示 115/10/25，綁定值為 2026/10/25 -->
<ShuoDatepicker v-model="applyDate" />
```

### 📐 一致的尺寸與狀態

所有表單輸入元件共用 `size`、`disabled`、`loading`、`skeleton`、`id`、`name`，同尺寸的元件高度一致，並會跟著 `UFormField` 與 `UForm` 的尺寸、停用與錯誤狀態走：[共用參數](https://k90325248.github.io/shuo-ui/components/overview/common)

```vue
<UForm :schema="schema" :state="state" :disabled="saving">
  <UFormField label="金額" name="amount" size="md">
    <ShuoInputNumber v-model="state.amount" :skeleton="loading" />
  </UFormField>
</UForm>
```

### ⚙️ 全站預設值與共用驗證規則

尺寸、顯示格式、圖示等可在 `nuxt.config.ts` 統一設定，元件上明確傳入的值仍然優先；常用的 Valibot 驗證規則已自動匯入，錯誤訊息格式全站一致：[元件全站預設值](https://k90325248.github.io/shuo-ui/getting-started/theme/component-defaults)、[表單驗證](https://k90325248.github.io/shuo-ui/getting-started/form/validation)

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/ui', '@shuo/ui'],
  shuoUi: {
    components: {
      selectMenu: { format: '{value}_{label}' },
      listCard: { pageSize: 20 }
    }
  }
});
```

```ts
const schema = v.object({
  name: requiredText('姓名'),
  amount: requiredNumber('金額')
});
```

### 🔎 查詢頁版面

`ShuoQueryCard` 放查詢條件、`ShuoListCard` 放查詢結果與後端分頁，查詢中的骨架、空資料與高度過渡都已處理：[查詢條件卡片](https://k90325248.github.io/shuo-ui/components/layout/query-card)、[清單卡片](https://k90325248.github.io/shuo-ui/components/layout/list-card)

## 🚀 新增元件

- **InputText:** 單行文字輸入，可遮蔽全部或最後幾碼（[文件](https://k90325248.github.io/shuo-ui/components/text/input-text)）
- **InputNumber:** 數字輸入，離開輸入框後顯示千分位，可指定小數位數與單位（[文件](https://k90325248.github.io/shuo-ui/components/text/input-number)）
- **Textarea:** 多行文字輸入，保留換行，可自動調整高度（[文件](https://k90325248.github.io/shuo-ui/components/text/textarea)）
- **SelectMenu:** 下拉選單，可搜尋、多選，文字過長時顯示完整提示（[文件](https://k90325248.github.io/shuo-ui/components/choice/select-menu)）
- **Datepicker:** 日期選擇器，預設民國年，支援五種精度與範圍選擇（[文件](https://k90325248.github.io/shuo-ui/components/date/datepicker)）
- **Checkbox:** 單一核取方塊，可自訂勾選值，文字旁可放附加內容（[文件](https://k90325248.github.io/shuo-ui/components/choice/checkbox)）
- **RadioGroup:** 單選群組，依視窗寬度自動排列，支援自訂選項欄位與附加內容（[文件](https://k90325248.github.io/shuo-ui/components/choice/radio-group)）
- **CheckboxGroup:** 複選群組，依視窗寬度自動排列，支援自訂選項欄位與附加內容（[文件](https://k90325248.github.io/shuo-ui/components/choice/checkbox-group)）
- **File:** 單檔選擇與既有附件下載，選檔不會自動上傳（[文件](https://k90325248.github.io/shuo-ui/components/phone-file/file)）
- **Months:** 年月數換算輸入，可同時綁定總月數、年數與月數（[文件](https://k90325248.github.io/shuo-ui/components/date/months)）
- **Phone:** 市話號碼，兩個輸入框分別輸入區碼與電話（[文件](https://k90325248.github.io/shuo-ui/components/phone-file/phone)）
- **QueryCard:** 可收合的查詢條件卡片，內含 UForm，欄位以響應式格線排列（[文件](https://k90325248.github.io/shuo-ui/components/layout/query-card)）
- **ListCard:** 查詢結果清單卡片，包含標題列、表格與後端分頁（[文件](https://k90325248.github.io/shuo-ui/components/layout/list-card)）
- **Table:** 基於 UTable 的純表格，含骨架、空資料與高度過渡（[文件](https://k90325248.github.io/shuo-ui/components/layout/table)）
- **InfoTooltip:** 資訊圖示加提示，滑鼠移入或鍵盤聚焦即顯示（[文件](https://k90325248.github.io/shuo-ui/components/helper/info-tooltip)）

## 🐛 Bug Fixes

- **module:** 只把已安裝圖示集的圖示加入 `@nuxt/icon` 的 client bundle。`1.0.0` 固定加入內建的 lucide 圖示，專案沒有安裝 `@iconify-json/lucide` 時，`nuxt build`、`nuxt generate` 會因無法產生 client bundle 而失敗；現在沒有安裝也能建置，圖示改由 `@nuxt/icon` 在執行時載入。建議一併安裝 `@iconify-json/lucide`，讓圖示直接打包進網站。

## ⚠️ 使用前須知

- 核取方塊與選項群組（`ShuoCheckbox`、`ShuoRadioGroup`、`ShuoCheckboxGroup`）的高度與輸入框對齊，因此不支援 Nuxt UI 的說明文字（`description`、`descriptionKey`）、`variant`（card、table）、`indicator` 與 `highlight`，傳入時型別會報錯，執行時也不會套用。
- `ShuoInputNumber` 不提供原生 `min`、`max`、`step`，數值範圍請用驗證規則。
- 選檔不會自動上傳：`ShuoFile` 只負責選擇與下載，上傳時機由頁面決定。

## 📦 安裝

```bash
pnpm add github:k90325248/shuo-ui#v1.0.1
pnpm add @iconify-json/lucide # 建議，圖示會直接打包
```

在 `nuxt.config.ts` 啟用模組，並在 CSS 加上 `@import '@shuo/ui/css';`，步驟見文件網站的[安裝](https://k90325248.github.io/shuo-ui/getting-started/overview/installation)。
