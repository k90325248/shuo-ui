# v1.1.0

> 發佈於 2026年10月26日

新增 `ShuoTooltip`，手機上長按即可查看所有提示；元件文案改為跟隨 Nuxt UI 的語系，內建繁體中文與英文。文件網站同步推出英文版，並重新整理成分頁與分組。升級前請先看下方的「升級須知」：自動匯入的函式範圍與元件文案的語系行為有調整。

## ✨ Highlights

### 📱 手機上長按查看提示

Nuxt UI 的 `UTooltip` 只在滑鼠移入或鍵盤聚焦時顯示，手機上點擊、按住都不會出現。新的 `ShuoTooltip` 沿用 `UTooltip` 的全部參數與 slot，補上觸控裝置的長按顯示；`ShuoInfoTooltip` 與下拉選單、日期選擇器、檔案選擇、核取方塊、選項群組的文字截斷提示都改用它，在手機上一樣長按顯示：[Tooltip](https://k90325248.github.io/shuo-ui/components/helper/tooltip)

```vue
<ShuoTooltip text="儲存草稿">
  <UButton label="儲存" />
</ShuoTooltip>
```

長按顯示提示時不會觸發原本的點擊、勾選或開啟選單。要恢復 Nuxt UI 原本的行為，單一元件傳 `:touch="false"`，或在全站設定 `components.tooltip.touch: false`。

### 🌐 元件文案跟隨 Nuxt UI 語系

驗證訊息、無障礙名稱、提示文字、日期選擇器的月份與星期等文案，跟著 `<UApp :locale>` 切換，內建繁體中文與英文，已顯示的元件會立即更新。文案可依語系覆寫，也可以加入內建以外的語系：[多語系與文案](https://k90325248.github.io/shuo-ui/getting-started/theme/messages)

```ts
export default defineNuxtConfig({
  shuoUi: {
    locale: 'zh-TW', // 頁面沒有設定 UApp 語系時使用
    locales: {
      en: { listCard: { title: 'Search results' } }
    }
  }
});
```

### 🌙 深色模式的表單色票

停用中的輸入框在深色模式改用較暗的底色與較亮的文字，不再沿用淺色模式的顏色；輸入框邊框在深色模式改用較亮的主色。停用色也從固定的灰色改為 Nuxt UI 的中性色，色調跟著專案 `app.config.ts` 的 `ui.colors.neutral`。顏色由 `--ui-form-*` 變數決定，可在專案 CSS 以 `:root` 與 `.dark` 分別覆寫：[表單色票](https://k90325248.github.io/shuo-ui/getting-started/theme/theming#%E8%A1%A8%E5%96%AE%E8%89%B2%E7%A5%A8)

## 🚀 新增元件

- **Tooltip:** 基於 UTooltip 的提示，補上觸控裝置長按顯示（[文件](https://k90325248.github.io/shuo-ui/components/helper/tooltip)）

## 🐛 Bug Fixes

- **InputText:** 遮蔽的文字切換為明碼時，不再先閃一下所有文字。
- **Months:** 「年」「月」單位的寬度依文字調整，英文的 `yr`、`mo` 不會被截斷。

### 元件文案跟隨 UApp 的語系

先前元件文案固定為繁體中文。現在元件會跟隨 `<UApp :locale>`：

- 沒有設定 `UApp` 的 `locale`，或設定為繁體中文時，畫面和先前相同。
- 設定了其他語系（例如英文）的專案，升級後元件文案會跟著變成該語系。需要調整文字時，以 `shuoUi.locales` 依語系覆寫，見[多語系與文案](https://k90325248.github.io/shuo-ui/getting-started/theme/messages#%E8%A6%86%E5%AF%AB%E6%96%87%E6%A1%88)。

## 📦 安裝

```bash
pnpm add github:k90325248/shuo-ui#v1.1.0
pnpm add @iconify-json/lucide # 建議，圖示會直接打包
```

在 `nuxt.config.ts` 啟用模組，並在 CSS 加上 `@import '@shuo/ui/css';`，步驟見文件網站的[安裝](https://k90325248.github.io/shuo-ui/getting-started/overview/installation)。
