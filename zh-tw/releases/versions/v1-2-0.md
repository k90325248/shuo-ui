# v1.2.0

> 發佈於 2026年10月27日

新增 `ShuoSwitch`，切換後可以先呼叫 API，成功才更新、失敗自動復原；表格與清單卡片支援勾選；核取方塊、選項群組與開關支援說明文字。文件網站的元件更新紀錄改為依語系顯示。升級前請先看下方的「升級須知」：選項資料原本就帶有 `description` 欄位的群組，升級後會顯示說明。

## ✨ Highlights

### 🔀 切換後先處理、成功才更新的開關

新的 `ShuoSwitch` 沿用 `USwitch` 的參數，多了 `action`：切換後先顯示新的值並進入載入中、停用，處理函式回傳 `false` 或丟出錯誤時自動復原，其他回傳值才更新 `v-model` 並送出 `change`。適合切換當下就要呼叫 API 儲存的設定：[Switch](https://k90325248.github.io/shuo-ui/components/choice/switch)

```vue
<ShuoSwitch v-model="enabled" label="啟用帳號" :action="(value) => api.setEnabled(value)" />
```

高度與同尺寸的輸入框一致，文字過長時省略並以 Tooltip 顯示完整文字，與核取方塊相同；`size`、`color`、`loadingIcon` 可在全站設定 `components.switch`。按鈕不需要另外包裝，`UButton` 的 `loading-auto` 已提供相同的處理中狀態。

### ☑️ 表格與清單卡片勾選

`ShuoTable` 與 `ShuoListCard` 加上 `selectable` 後，在最前面加上勾選欄，勾選結果以 `v-model:selected` 綁定 key 陣列：[Table 的勾選](https://k90325248.github.io/shuo-ui/components/layout/table#%E5%8B%BE%E9%81%B8)

```vue
<ShuoListCard
  v-model:selected="selected"
  :data="rows"
  :columns="columns"
  selectable
  row-key="ID"
  :row-selectable="(row) => row.status !== '已結案'"
  @page-change="search"
/>
```

- `row-key` 為欄位名稱或函式；後端分頁時換頁仍保留其他頁的勾選，可以一次處理多頁勾選的資料。
- 表頭的全選只勾選目前這頁可勾選的資料，部分勾選時顯示半選；`select-all` 設為 `false` 時改顯示 `selection-header` 的文字。
- `row-selectable` 回傳 `false` 的資料停用勾選；查詢中停用所有核取方塊。
- `checkbox-props` 設定核取方塊的 `class`、`ui`、`color`、`size` 與圖示；`columns` 中放 `{ id: 'select' }` 可指定勾選欄的位置，`#select-header`、`#select-cell` 插槽可完全自訂。
- `selectAll`、`checkboxProps` 可在全站設定 `components.table`。

沒有開啟 `selectable` 時行為不變，先前以 `tableProps` 自行控制勾選的寫法照常可用。

### 📝 核取方塊、選項群組與開關的說明文字

`ShuoCheckbox`、`ShuoRadioGroup`、`ShuoCheckboxGroup` 與 `ShuoSwitch` 支援說明文字（群組以選項的 `description` 欄位或 `description-key` 指定）。沒有說明時高度仍與輸入框一致；有說明時往下撐高、說明換行，第一行文字仍與旁邊的欄位對齊。水平排列的群組整列一起撐高，說明不會擠壓其他選項的文字：[Checkbox 的說明文字](https://k90325248.github.io/shuo-ui/components/choice/checkbox#%E8%AA%AA%E6%98%8E%E6%96%87%E5%AD%97)

```vue
<ShuoCheckbox v-model="subscribe" label="訂閱電子報" description="每週寄送一次最新公告，可以隨時取消" />
```

## 🚀 新增元件

- **Switch:** 開關，切換後可先執行處理函式，成功才更新綁定值，失敗或丟出錯誤時自動復原（[文件](https://k90325248.github.io/shuo-ui/components/choice/switch)）

## ⚠️ 升級須知

### 選項資料的 description 欄位會顯示

先前單選與複選群組不顯示選項說明，選項資料就算帶有 `description` 欄位也會被忽略。現在會顯示在選項文字下方，並讓選項撐高。

選項直接使用後端資料、而資料剛好有 `description` 欄位（例如代碼表的備註）時，升級後畫面會多出說明。不想顯示時，在傳入前移除該欄位：

```ts
const options = computed(() => codes.value.map(({ description: _description, ...item }) => item));
```

## 📖 文件網站

- **版本紀錄：** 標題列新增「版本紀錄」分頁，可查看每個版本的發佈說明，與 GitHub Release 內容相同，英文版顯示英文說明。
- **更新紀錄依語系顯示：** 元件頁最後的更新紀錄改為依文件語系顯示中文或英文說明，不再顯示 `feat:`、`fix:` 等前綴。
- **新頁面：** 新增 [Switch](https://k90325248.github.io/shuo-ui/components/choice/switch)；Table、ListCard、Checkbox、RadioGroup、CheckboxGroup 頁新增勾選與說明文字的用法與範例；共用參數頁的範例加入開關。

## 📦 安裝

```bash
pnpm add github:k90325248/shuo-ui#v1.2.0
pnpm add @iconify-json/lucide # 建議，圖示會直接打包
```

在 `nuxt.config.ts` 啟用模組，並在 CSS 加上 `@import '@shuo/ui/css';`，步驟見文件網站的[安裝](https://k90325248.github.io/shuo-ui/getting-started/overview/installation)。
