# v1.3.0

> 發佈於 2026年10月29日

表格與清單卡片的初次載入骨架可以調整列數與高度，也可以全站設定。沒有設定時與 1.2.1 相同，升級不需要修改程式碼。

## ✨ Highlights

### 🦴 調整初次載入骨架的列數與高度

`ShuoTable` 與 `ShuoListCard` 新增 `skeleton-rows` 與 `skeleton-class`：前者設定骨架列數（預設 `3`，至少 1 列），後者設定每條骨架的高度等樣式（預設 `h-6`，即 24px，傳入時整個取代預設值）：[Table 的初次載入骨架](https://k90325248.github.io/shuo-ui/components/layout/table#%E5%88%9D%E6%AC%A1%E8%BC%89%E5%85%A5%E9%AA%A8%E6%9E%B6)

```vue
<ShuoListCard :data="rows" :columns="columns" :loading="loading" :skeleton-rows="5" skeleton-class="h-8" />
```

兩者都可在全站設定 `components.table` 統一調整，也套用到 `ShuoListCard` 內的表格；頁面明確傳入時優先：

```ts
export default defineNuxtConfig({
  shuoUi: {
    components: {
      table: { skeletonRows: 5, skeletonClass: 'h-8' }
    }
  }
});
```

## 📖 文件網站

- Table、ListCard 與[全站元件預設值](https://k90325248.github.io/shuo-ui/getting-started/theme/component-defaults)頁新增骨架列數與高度的說明。

## 📦 安裝

```bash
pnpm add github:k90325248/shuo-ui#v1.3.0
pnpm add @iconify-json/lucide # 建議，圖示會直接打包
```

在 `nuxt.config.ts` 啟用模組，並在 CSS 加上 `@import '@shuo/ui/css';`，步驟見文件網站的[安裝](https://k90325248.github.io/shuo-ui/getting-started/overview/installation)。
