# v2.0.0

> 發佈於 2026年11月2日

下拉選單與日期選擇器的清除按鈕統一為 `clear`，並改為預設開啟。日期選擇器的 `clearable` 已改名，升級前請先看下方的升級須知。

## ✨ Highlights

### ✖️ 清除按鈕統一為 `clear`，預設開啟

`ShuoSelectMenu` 新增 `clear` 與 `clear-icon`：已選取時尾端以清除按鈕取代箭頭，清除後單選為 `empty-value`、多選為 `[]`，停用或載入中時不顯示：[SelectMenu 的清除按鈕](https://k90325248.github.io/shuo-ui/components/choice/select-menu#%E6%B8%85%E9%99%A4%E6%8C%89%E9%88%95)

`ShuoDatepicker` 的 `clearable` 改名為 `clear`，與下拉選單一致：[Datepicker 的圖示與清除按鈕](https://k90325248.github.io/shuo-ui/components/date/datepicker#%E5%9C%96%E7%A4%BA%E8%88%87%E6%B8%85%E9%99%A4%E6%8C%89%E9%88%95)

兩者都預設開啟，不需要時傳 `:clear="false"`：

```vue
<ShuoSelectMenu v-model="state.type" :items="items" :clear="false" />
<ShuoDatepicker v-model="state.date" :clear="false" />
```

包在 `required` 的 `UFormField` 內時預設關閉，避免必填欄位一鍵清空；需要時仍可明確傳 `clear`：

```vue
<UFormField label="類別" name="type" required>
  <ShuoSelectMenu v-model="state.type" :items="items" />
</UFormField>
```

也可以在全站設定分別調整，判斷順序為：明確傳入的 `clear` > `UFormField` 的 `required` > 全站設定 > 內建預設（開啟）：

```ts
export default defineNuxtConfig({
  shuoUi: {
    components: {
      selectMenu: { clear: false },
      datepicker: { clear: true }
    }
  }
});
```

## ⚠️ 升級須知

### `clearable` 改名為 `clear`

`ShuoDatepicker` 的 `clearable` 與全站設定 `components.datepicker.clearable` 都改為 `clear`。舊名稱不再生效：元件上的 `clearable` 會被當成一般屬性忽略，全站設定則會在啟動時警告並略過。請全專案搜尋 `clearable` 改為 `clear`；原本寫 `clearable` 開啟清除的地方，除了必填欄位（見下一節）之外，現在預設就有清除按鈕，可以直接刪除。

### 清除按鈕預設顯示

先前下拉選單沒有清除按鈕，日期選擇器預設不顯示。升級後兩者有值時都會顯示清除按鈕（包在 `required` 的 `UFormField` 內除外），下拉選單已選取時尾端的箭頭也會改為清除按鈕。要維持先前的行為，在全站設定關閉：

```ts
export default defineNuxtConfig({
  shuoUi: {
    components: {
      selectMenu: { clear: false },
      datepicker: { clear: false }
    }
  }
});
```

原本在必填欄位寫 `clearable` 的日期選擇器，改名後要寫 `clear` 才會顯示清除按鈕；直接刪除會因為必填而不顯示。只在 schema 設必填、`UFormField` 沒寫 `required` 的欄位仍會顯示清除按鈕，不想顯示時在 `UFormField` 加上 `required` 或傳 `:clear="false"`。

寬度很窄（約 90px 以下）的欄位顯示清除按鈕後，文字可能沒有空間顯示，這類欄位請傳 `:clear="false"`。

## 📦 安裝

```bash
pnpm add github:k90325248/shuo-ui#v2.0.0
pnpm add @iconify-json/lucide # 建議，圖示會直接打包
```

在 `nuxt.config.ts` 啟用模組，並在 CSS 加上 `@import '@shuo/ui/css';`，步驟見文件網站的[安裝](https://k90325248.github.io/shuo-ui/getting-started/overview/installation)。
