# v3.2.2

> 發佈於 2026年11月17日

把 `@nuxt/ui` 的最低版本提高到 `4.12.2`，以修補 critical 等級的安全漏洞；並修正以鍵盤在選項群組間移動焦點時，完整文字提示立即關閉的問題。從 3.2.1 升級不需要修改程式碼，但專案的 `@nuxt/ui` 須一併升級到 `4.12.2` 以上。

## 🔒 Security

- **@nuxt/ui 最低版本改為 ^4.12.2（GHSA-x9jw-j844-v24h，CVSS 9.8）：** `@nuxt/ui` 4.12.2 以前的元件會把 `as` 原樣交給 reka-ui 的 `Primitive`，帶有 `template` 的物件會在 SSR 時被 Vue 的 CJS server renderer 編譯執行。以 Comark 或 MDC（`@nuxt/content`）渲染不受信任的 Markdown，或讓不受信任的資料寫入 `app.config.ui`、`<UTheme :props>` 的專案，可能因此在伺服器上被執行任意指令。Shuo UI 的元件本身沒有使用 `as`、`resolveAs` 或 `UTheme`，但會跟著專案使用同一份 `@nuxt/ui`，因此提高 peer 依賴的最低版本，安裝時會提示升級。

升級方式：

```bash
pnpm add @nuxt/ui@^4.12.2
```

## 🐛 Bug Fixes

- **以鍵盤在選項間移動焦點時，完整文字提示立即關閉：** `ShuoCheckboxGroup` 以 Tab、`ShuoRadioGroup` 以方向鍵移到另一個文字被省略的選項時，提示會先關閉再開啟，Reka 尚未卸載的舊提示收到開啟事件後，連同新提示一起關閉。現在焦點仍在群組內時不關閉提示，直接更新為目前選項的文字與位置；焦點移出群組時照常關閉。

## 📦 安裝

```bash
pnpm add github:k90325248/shuo-ui#v3.2.2
pnpm add @iconify-json/lucide # 建議，圖示會直接打包
```

在 `nuxt.config.ts` 啟用模組，並在 CSS 加上 `@import '@shuo/ui/css';`，步驟見文件網站的[安裝](https://k90325248.github.io/shuo-ui/getting-started/overview/installation)。
