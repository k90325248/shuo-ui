# v3.3.1

> 發佈於 2026年11月24日

修正 Nuxt UI 的 toast 卡住的問題：在特定操作後跳出的新 toast 沒有進度條，也不會自動關閉。從 3.3.0 升級不需要修改程式碼。

## 🐛 Bug Fixes

- **新 toast 沒有進度條、不會自動關閉：** 這是 reka-ui 2.11.0（目前最新版）的 bug。滑鼠停在 toast 上時，關掉最後一個 toast（呼叫 `toast.remove()`、點 action、滑動關閉，或在點按鈕不會取得焦點的瀏覽器上點 X），toast 的暫停狀態不會解除，下一個 toast 就不會計時。Shuo UI 現在會在新 toast 出現、而且此刻不該暫停（視窗聚焦、滑鼠與焦點都不在 toast 上）時，讓 reka-ui 恢復計時。滑鼠停在 toast 上、視窗失焦時仍會照常暫停。

## ✨ 新選項

- **shuoUi.toastPauseFix（預設 true）：** 上述修正的開關，設為 `false` 可停用。reka-ui 修好後，修正與這個選項會一併移除：[模組選項](https://k90325248.github.io/shuo-ui/getting-started/theme/module-options)

## 📦 安裝

```bash
pnpm add github:k90325248/shuo-ui#v3.3.1
pnpm add @iconify-json/lucide # 建議，圖示會直接打包
```

在 `nuxt.config.ts` 啟用模組，並在 CSS 加上 `@import '@shuo/ui/css';`，步驟見文件網站的[安裝](https://k90325248.github.io/shuo-ui/getting-started/overview/installation)。
